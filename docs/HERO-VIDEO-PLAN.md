# 히어로 루프 영상 기획 — "내가 만든 게임을 친구가 한다"

랜딩 히어로의 작품 격자 안, 가장 큰 칸(2×2)에 들어가는 무음 루프 영상이다.
([LANDING-PLAN.md](./LANDING-PLAN.md) 1일 섹션, [시안](../prototypes/landing-month.html))

## 확정 사항

| 항목 | 결정 |
|---|---|
| 게임 | 실제 작품 **텐팡** — https://lounge.letscoding.kr/works/nana/ten-pang |
| 등장 인물 | 두 명. 만든 사람, 해 보는 친구. 세 번째 사람은 없다 |
| 댓글 문구 | **최고야! 나도 해보고 싶어!** |
| 손 모델 | 학생. 작성자 이름은 가린다 (6장) |
| 길이 | 12초 루프 |

## 1. 이 영상의 조건

| 조건 | 이유 |
|---|---|
| **무음** | 자동재생 루프라 소리가 없다. 자막 없이 그림만으로 읽혀야 한다 |
| **얼굴 없음** | 손, 소매, 화면만 나온다. 초상권 부담을 없애고, 보는 사람이 자기 학원 아이를 대입하게 한다 |
| **작은 칸에서도 읽힘** | 데스크톱에서 약 400×300px로 보인다. 화면 속 글자는 거의 안 읽힌다고 가정하고 **색, 모양, 움직임**으로 전달한다 |
| **끊김 없는 루프** | 마지막 프레임이 첫 프레임으로 자연스럽게 이어져야 한다 |
| **정지 프레임 하나로도 뜻이 남음** | 움직임 줄이기 설정 사용자와 느린 네트워크에서는 포스터 한 장만 보인다 |
| **최대한 단순하게** | 사람 둘, 기기 둘(노트북과 휴대폰), 컷 다섯 |

## 2. 길이: 12초

- 이야기에 필요한 최소 비트가 다섯 개다. 만든다 → 보낸다 → 해 본다 → 돌아온다 → 다시 만든다.
- 한 비트에 2초는 있어야 처음 보는 사람도 알아본다. 10초 아래로 줄이면 "무슨 일이 일어났는지" 놓친다.
- 15초를 넘기면 루프가 아니라 "기다려야 하는 영상"이 된다.
- 12초면 웹용 파일을 2~3MB 안에 맞출 수 있다.

## 3. 게임: 텐팡

**게임 방식:** 합이 10이 되는 숫자 풍선을 찾아 터뜨린다. PC, 태블릿, 스마트폰을 모두 지원한다.

**영상에 맞는 점**
- **휴대폰으로 할 수 있다.** "친구가 링크를 받아 휴대폰에서 바로 한다"는 라운지의 핵심 장면을 그대로 찍을 수 있다.
- **풍선이 터지는 순간**은 색과 움직임이 커서 400×300px 칸에서도 읽힌다.
- 타이틀 화면(노란 "텐팡" 로고, 빨강·파랑·초록 숫자 풍선)이 강하고 단순해서, 두 화면에서 "같은 게임"으로 바로 알아본다.
- **랜딩 페이지 10일 섹션**("아이가 만든 게임, 지금 해 보세요")에서 방문자가 직접 해 보는 게임도 텐팡이다. 히어로 영상에서 본 게임을 아래로 내려와 직접 하게 되므로, 영상과 페이지가 이어진다.

**주의**
- 작품 페이지의 **랭킹 TOP 10**에 실제 플레이어 활동명이 보인다. 화면이 잡히면 흐리게 처리하거나 촬영용 계정의 기록만 보이게 한다.

## 4. 누구라도 이해하게 만드는 세 가지 장치

1. **같은 게임이 두 화면에 나온다.** 만든 사람의 노트북에서 보던 텐팡이 친구의 **휴대폰**에서 똑같이 실행된다. "저게 그거구나"가 이 영상 이해의 전부다. 기기가 달라서(노트북 → 휴대폰) "다른 사람에게 갔다"도 저절로 읽힌다.
2. **소매 색으로 사람을 구분한다.** 얼굴이 없으니 옷이 사람을 대신한다.
   - 만든 사람: **노란 소매** (루캣의 금색과 같은 계열)
   - 해 보는 친구: **파란 소매** (페이지의 포인트 블루와 같은 계열)
   - 무늬 없는 단색 긴소매 후드로 맞춘다.
3. **반응이 화면으로 돌아온다.** 친구의 표정 대신, 만든 사람의 노트북에 **댓글 "최고야! 나도 해보고 싶어!"와 하트, 조회수가** 뜨는 모습으로 반응을 보여 준다.

## 5. 스토리보드 (12초 · 30fps · 5컷)

화면비는 **4:3**으로 편집한다. 모바일에서는 중앙 3:4 세로로 다시 잘라 쓸 수 있도록, 각 컷의 핵심 동작은 **중앙 3분의 1 안**에 둔다.

---

### 컷 1 · 만든다 (0.0 ~ 2.5초)

```
┌─────────────────────────────┐
│   ┌───────────────────┐     │
│   │  텐팡 🎈 타이틀 화면 │     │  노트북. 어깨 너머 45°
│   └───────────────────┘     │
│  🟨 손 ── 트랙패드          │  노란 소매의 손
└─────────────────────────────┘
```

- **화면:** 노트북에 텐팡 타이틀 화면이 떠 있다. 노란 소매의 손이 트랙패드로 라운지 작품 페이지의 **"공유"** 버튼을 누른다.
- **카메라:** 고정. 어깨 너머 45°.
- **전달할 것:** 이 사람이 이 게임을 만들었고, 지금 내보낸다.
- **루프 연결점:** 이 컷의 첫 프레임은 컷 5의 마지막 프레임과 같은 구도다.

### 컷 2 · 보낸다 (2.5 ~ 4.5초)

```
┌─────────────────────────────┐
│                             │
│        ┌─────┐              │  책상 위에 놓인 휴대폰
│        │ 🔗  │ ← 화면이 켜짐 │  링크 카드에 텐팡 썸네일
│        │[썸네일]│            │
│        └─────┘              │
│              🟦 손이 들어옴  │  파란 소매 손이 프레임 안으로
└─────────────────────────────┘
```

- **화면:** 책상 위 휴대폰이 켜지고 링크 카드가 뜬다. **썸네일이 컷 1의 텐팡 타이틀과 같은 그림**이다. 파란 소매의 손이 들어와 휴대폰을 집는다.
- **카메라:** 고정. 탑뷰(바로 위).
- **전달할 것:** 링크 하나가 친구에게 갔다.
- **편집:** 컷 1의 "공유" 클릭에 맞춰 휴대폰이 켜지는 **액션 컷**으로 잇는다.
- **화면 녹화:** 알림 카드는 실제 메신저 화면을 녹화한다. 실존 서비스 로고가 크게 보이면 흐리게 처리한다.

### 컷 3 · 해 본다 (4.5 ~ 8.5초) — 이 영상의 중심

```
┌─────────────────────────────┐
│          ┌───────┐          │  파란 소매 손이 휴대폰을 세로로 쥠
│          │  🎈6   │          │  가운데 풍선 하나
│      🟦  │  💥    │          │  아래 숫자 칸에서 4를 탭 → 6+4=10, 풍선이 터짐
│          │[6][4][1]│         │
│          └───────┘          │
└─────────────────────────────┘
```

- **화면:** 가운데 숫자 풍선(6)이 떠 있고, 파란 소매의 엄지가 아래 숫자 칸 중 **합이 10이 되는 칸(4)**을 탭한다. 풍선이 터지고 점수가 오르고, 다음 풍선(9)이 나온다. 다시 1을 탭해 터뜨린다.
- **카메라:** 휴대폰 화면을 정면에서 약간 위로. 느린 푸시인(조금씩 다가감). 터지는 효과(노란 고리와 작은 점)가 가늘어서, **휴대폰 화면이 프레임을 넓게 채워야** 작은 칸에서도 보인다.
- **전달할 것:** 다른 사람이 내 게임을 하고 있다.

**녹화 소스 (2026-09-25 받음)**

| 용도 | 파일 | 구간 | 처리 |
|---|---|---|---|

- `Screen_Recording_20260925_222209_Chrome.mp4`(18.7초)는 게임 종료 화면, 작품 페이지, 랭킹, 알림창이다. 랭킹에 활동명이, 알림창에 개인 메신저 내용이 보여서 **영상에는 쓰지 않는다.** 작품 페이지 부분(조회·플레이·좋아요·댓글 수 배치)은 노트북 화면을 생성할 때 참고 자료로만 쓴다.

### 컷 4 · 돌아온다 (8.5 ~ 10.5초)

```
┌─────────────────────────────┐
│   ┌───────────────────┐     │  다시 노트북. 라운지 작품 페이지  
│   │ 💬 최고야!          │ ← 댓글이 뜬다
│   │    나도 해보고 싶어! │     │
│   │ ♥ +1   👁 +1        │     │
│   └───────────────────┘     │
│  🟨 손이 살짝 주먹을 쥠       │
└─────────────────────────────┘
```

- **화면:** 다시 노트북이다. 라운지 작품 페이지에 댓글 **"최고야! 나도 해보고 싶어!"**가 뜨고, 하트가 하나 붙고, 조회수가 오른다. 노란 소매의 손이 트랙패드 옆에서 **작게 주먹을 쥔다.**
- **카메라:** 컷 1과 같은 구도. 조금 더 가깝게. 댓글 부분에 살짝 줌인한다.
- **전달할 것:** 반응이 만든 사람에게 돌아왔다.
- **화면 녹화:** 실제 라운지 작품 페이지에서 댓글을 달고 좋아요를 누르는 과정을 녹화한다. 댓글 작성자의 활동명이 보이면 흐리게 처리하거나 촬영용 계정을 쓴다.
- **댓글 크기:** 작은 칸에서 문구는 안 읽혀도 "말풍선이 떴다"는 것은 보여야 한다. 줌인과 말풍선 등장 애니메이션으로 강조한다.

### 컷 5 · 다시 만든다 (10.5 ~ 12.0초)

- **화면:** 노란 소매의 손이 키보드로 돌아가고, 노트북이 편집 화면(코드 또는 AI 채팅)으로 바뀐다.
- **카메라:** 컷 1과 **완전히 같은 구도**로 끝난다. 마지막 0.5초는 컷 1 첫 프레임과 크로스디졸브한다.
- **전달할 것:** 반응을 보고 다시 고친다. 그리고 이야기가 처음으로 돌아간다(루프).

## 6. 만든 사람의 표현 (결정: 2026-09-25)

이 작품의 실제 작성자는 **나나쌤**이다. 영상은 **학생 손**으로 찍는다. 그래서 아래를 지킨다.

- 영상 어디에도 "학생 작품", "학생이 만든" 같은 말을 쓰지 않는다.
- 컷 1과 컷 4에서 작품 페이지의 **작성자 이름("나나쌤")을 가린다.** 흐림 처리하거나 해당 영역을 화면 밖으로 잘라낸다.
- 랭킹 TOP 10의 활동명도 같이 가린다.
- 영상을 쓰는 랜딩 페이지에서도 이 게임을 "아이가 만든 게임"이라고 부르지 않는다.

## 7. 촬영 준비

**출연:** 손 모델 2명. 노랑, 파랑 단색 긴소매 후드를 입고, 반지나 시계는 뺀다.
**장소:** 실제 학원 교실의 책상. 배경은 흐리게 날리되 교실이라는 것은 알아볼 수 있게.
**장비와 소품:**
- 노트북 1대, 휴대폰 1대. 화면 밝기를 최대로 하고, 휴대폰은 알림 미리보기를 켠다.
- 삼각대와 탑뷰 암(컷 2)
- 책상 위에는 소품을 최소로 둔다. 물병이나 과자 봉지 같은 브랜드 로고가 보이는 물건은 치운다.
- 노트북과 휴대폰의 로고, 케이스 무늬, 스티커는 가린다.

**화면 녹화 (60fps, 따로 녹화해 두기)**
- 텐팡 타이틀 화면(노트북), 휴대폰 플레이 화면(풍선 2~3번 터뜨리기)
- 라운지 작품 페이지의 "공유" 클릭
- 휴대폰의 링크 알림 카드
- 작품 페이지에 댓글 "최고야! 나도 해보고 싶어!"가 달리고 좋아요가 눌리는 과정
- 촬영본 화면이 반사되거나 흔들리면 녹화본으로 교체 합성한다.

**촬영 설정:** 4K 30fps로 찍어 4:3으로 자른다. 화이트밸런스는 고정하고, 조명은 창 반대편에서 부드럽게.

**동의:** 손 모델(미성년자면 보호자 동의), 화면에 나오는 활동명.

## 10. 촬영 목록 (현장용)

촬영은 두 종류다. **카메라 촬영**(손과 기기)과 **화면 녹화**(기기 안의 화면). 카메라로 찍은 화면이 반사되거나 흐리면 녹화본으로 교체 합성한다. 그래서 둘 다 찍는다.

### A. 노트북 화면 — 이미지·영상 생성으로 대체 (결정: 2026-09-25)

노트북 화면은 녹화하지 않고 생성한다. 아래 표는 **생성할 화면의 내용**이다. 생성할 때 지킬 것:
- 실제 라운지 화면 구성(작품 썸네일, 공유 버튼, 좋아요, 댓글 영역)과 같게 만든다. 없는 기능을 그리지 않는다.
- 텐팡 썸네일은 실제 이미지를 그대로 넣는다. 휴대폰 화면(B)과 같은 게임으로 보여야 한다.
- 작성자 이름과 활동명은 처음부터 넣지 않는다.

| # | 쓸 컷 | 생성할 화면 | 길이 |
|---|---|---|---|
| L1 | 컷 1 | 텐팡 작품 페이지. 썸네일이 크게 보이는 상태에서 커서가 **"공유"** 버튼으로 천천히 이동해 클릭 → "링크 복사됨" 표시 | 6초 |
| L2 | 컷 4 | 같은 작품 페이지의 **댓글 영역 — 댓글이 달리기 전** 상태 | 4초 |
| L3 | 컷 4 | 같은 영역 — 댓글 **"최고야! 나도 해보고 싶어!"**가 달리고, 좋아요가 1 늘어난 **후** 상태 | 4초 |
| L4 | 컷 5 | 텐팡을 고치는 편집 화면(코드 편집기나 AI 채팅). 타이핑이 이어지는 장면 | 6초 |

- L2와 L3는 같은 화면 구도로 만든다. 편집에서 댓글이 "팡" 하고 나타나는 연출로 둘을 잇는다.

### B. 화면 녹화 — 휴대폰 (세로)

녹화 전 준비: 방해 금지 모드, 배터리·시간이 보이는 상태 표시줄은 편집에서 잘라낸다.

| # | 쓸 컷 | 녹화할 화면 | 길이 |
|---|---|---|---|
| P1 | 컷 2 | 잠금화면 또는 홈 화면에 **링크 알림 카드**가 뜨는 순간. 텐팡 썸네일이 보여야 한다 (촬영용 계정끼리 메신저로 링크를 보낸다) | 5초 |
| P2 | 컷 3 | ✅ 받음 (컷 3 "녹화 소스" 참고) | — |
| P3 | 포스터 | ✅ P2의 12.25초 프레임 | — |

- 세 번 이상 찍어 두고 가장 깔끔하게 터지는 판을 고른다.
- 메신저 로고가 크게 보이면 편집에서 흐리게 한다.

### C. 카메라 촬영 — 손과 기기

모든 컷을 **앞뒤로 2초씩 더** 찍는다. 삼각대는 컷 안에서 절대 움직이지 않는다(컷 3의 푸시인은 편집에서 만든다).

| # | 쓸 컷 | 구도 | 출연 | 동작 |
|---|---|---|---|---|
| C1 | 컷 1·4·5 | 노트북을 어깨 너머 45° | 🟨 노란 소매 | ① 트랙패드로 "공유" 클릭 ② 화면을 보다가 **작게 주먹 쥐기** ③ 키보드로 돌아가 타이핑 |
| C2 | 컷 2 | 책상 위 휴대폰을 바로 위(탑뷰)에서 | 🟦 파란 소매 | 휴대폰 화면이 켜진 뒤 1초 기다렸다가, 손이 프레임 밖에서 들어와 휴대폰을 집어 든다 |
| C3 | 컷 3 | 휴대폰 화면을 정면에서 약간 위로 | 🟦 파란 소매 | 한 손으로 휴대폰을 세로로 쥐고 엄지로 풍선을 탭 |

- **C1은 한 자리에서 한 번에** 찍는다. 컷 1, 4, 5가 같은 구도여야 루프가 튀지 않는다. ①②③을 이어서 한 테이크로 찍고, 편집에서 나눈다.
- C1의 첫 프레임과 마지막 프레임에서 노란 손의 위치가 **비슷하도록** 동작을 맞춘다(루프 연결점).
- 소매는 매 테이크 같은 길이로 걷어 올린다. 반지와 시계는 뺀다.

## 11. KIE.AI 생성 계획 (결정: 2026-09-25)

**방식:** 손, 기기, 교실은 KIE.AI로 생성하고, **화면 안의 내용은 편집에서 넣는다.**

- 생성 모델은 화면 속 글자와 UI를 자주 틀리게 그린다. 그래서 생성할 때 기기 화면은 **균일한 초록색**(크로마키)으로 비워 두고, 편집에서 실제 화면(텐팡 녹화, 라운지 화면)을 끼워 넣는다.
- 모든 컷이 한 장소처럼 보이도록 **기준 이미지 한 장**을 먼저 만들고, 영상은 모두 그 이미지에서 시작한다(image-to-video).

### 댓글·링크 효과는 "모션 그래픽"으로

실제 라운지에는 댓글이 도착할 때 시각 효과가 없다. 그래서 효과는 **앱 화면처럼 꾸미지 않고, 화면 밖으로 떠오르는 그래픽**으로 만든다. 보는 사람이 "앱에 이런 애니메이션이 있다"가 아니라 "반응이 돌아왔다"로 읽게 하려는 것이다.

| 효과 | 쓸 컷 | 모양 |
|---|---|---|
| 링크 도착 | 컷 2 | 휴대폰 화면 위로 흰 카드가 톡 떠오른다. 텐팡 썸네일 + 🔗 아이콘. 실존 메신저(카카오톡 등)의 모양을 흉내 내지 않는다 |
| 댓글 도착 | 컷 4 | 노트북 화면에서 흰 말풍선이 떠올라 커진다. 문구 **"최고야! 나도 해보고 싶어!"** 옆에 ♥ +1 |

- 스타일은 랜딩 페이지와 맞춘다. 흰 면, 1px 헤어라인, 그림자 없음, 포인트 파랑 한 방울.
- 한글 문구는 생성하지 않고 **편집 툴에서 Pretendard로 타이핑**한다.
