# 랜딩 페이지 구성 기획 v2

정리일: 2026-09-29 · v1(한 학원의 한 달 달력 메타포)은 폐기하고 이 문서로 덮어썼다.

섹션 현황 확인일: 2026-10-02. 아래 번호는 현재 코드 주석 기준이며, 앞으로 랜딩 페이지를 논의할 때 사용하는 참조 번호다. 화면에 표시되는 번호나 HTML의 순번은 아니다.

## 0. 방향

**관객:** 코딩학원 원장님(교육 제공자). 학부모가 아니다.
**원장님의 어려움:** 한 명을 1년, 3년 지켜야 하는데 커리큘럼이 6개월이면 바닥난다. AI 시대에 무엇을 가르쳐야 할지 모른다. 학부모는 "AI가 다 해 주는데 왜 배워요?"라고 묻는다.
**원하는 반응:** "우리 학원 얘기다" → "그 교육은 이런 모양이구나" → "4주만 써 보자."

## 1. 이야기 뼈대 — 선언 → 왜 → 그래서 → 어떻게 → 어디서

| 주제 | 내용 |
|---|---|
| 주제1 | 학생 한 명이 스타트업이 되는 교육이 AI 시대에 필요한 교육이다 |
| 주제2 | 무한한 지식의 시대를 지나 무한 실행의 시대로 진입하고 있다 |
| 주제3 | 교육이 시대의 흐름에 발맞추어 변해야만 한다 |
| 결론 | 렛츠코딩 라운지 플랫폼에서 실현 가능하다 |

주제1은 히어로에서 선언하고, 시대 변화 → 성장 과정 → 라운지 공간 → 사이클 → 기능 → 한 달 수업 → 선생님 지원 → 상담 결과물 → 실측 → 도입 → FAQ → 마지막 제안으로 이어진다.

## 2. 현재 섹션 구성 (`src/app/page.tsx`)

2026-10-02 사용자가 선택한 `/v2`의 네 구간을 통합했다. 기존 7번 활동은 한 달 수업으로 확장하고, 선생님 지원·상담 결과물·FAQ를 추가하여 **1~13번**을 사용한다. 이전 8번 숫자는 10번, 9번 시작은 11번, 10번 마지막 제안은 13번이다.

| 번호 | 내용 | 헤드라인 |
|---|---|---|
| 1 | 히어로 | 학생 한 명이, 스타트업이 됩니다. |
| 2 | 시대 | 무한한 지식의 시대를 지나, 무한한 실행의 시대로 나아갑니다. |
| 3 | 성장 과정 | 만들고 공유하기, 성장하고 기록하기 |
| 4 | 라운지 공간 | 공동체가 함께 즐겁게 소통할 수 있는 놀이터같은 공간 |
| 5 | 세 축의 사이클 | 세가지 축이 서로 탄탄하게 연결되어 작품제작 활동이 역량 준비와 경제교육으로 이어지게 됩니다. |
| 6 | 기능 | 렛츠코딩라운지 기능소개 |
| 7 | 한 달 수업 | 다음 달 수업, 프로젝트 하나로. |
| 8 | 선생님 지원 | 선생님의 역할은 좋은 다음 질문을 건네는 일. |
| 9 | 상담 결과물 | “이번 달에 이걸 만들었어요.” |
| 10 | 운영 수치 | 지금 이순간도 새로운 작품들이 등록되고 있습니다. |
| 11 | 시작 | 반 하나면 충분합니다. 먼저, 4주만. |
| 12 | 도입 전 질문 | 궁금한 것부터 확인하세요. |
| 13 | 마지막 제안 | 다음 스타트업의 탄생을 기다립니다. |

- 번호는 화면의 콘텐츠 구간 기준이다. HTML `<section>` 개수와는 다르며, 3번은 소개와 스크롤 장면으로 나뉘고 4~6번은 하나의 `<section>` 안에 있다.
- 요청한 줄바꿈은 `<br />`로 명시했다. 문구 기준은 루트 `MODIFY.md`다.
- 7번 영상은 원본 `public/landing/video/lounge-shorts.mp4`의 17~21초를 별도 4초 무음 영상 `lounge-activity-loop.mp4`로 편집했다. 원본은 보존한다.
- 10번 숫자는 기준일이 있는 실측을 유지한다. 화면 진입 시 집계값의 십 단위부터 시작해 앞자리는 고정하고 일의 자리만 아래에서 위로 올라오는 세로 롤링으로 집계값까지 올라간 뒤 시작 숫자로 자연스럽게 이어져 무한 반복한다(220 → 224건, 40 → 45명, 8,680 → 8,689회, 410 → 419개). 실시간 데이터로 가장하거나 집계값을 임의로 늘리지 않는다. 동작 줄이기 설정에서는 애니메이션 없이 집계값을 표시한다.
- 2번의 학부모 질문과 개별 채용 사례는 기존처럼 숨겨 두었다.

확인 소스: [랜딩 페이지](../src/app/page.tsx), [스크롤 장면](../src/components/landing/scroll-scene.tsx), [숫자 연출](../src/components/landing/reveal-observer.tsx).

이전 기획 문서에 나오는 번호는 작성 당시 번호다. 앞으로의 대화에서는 위 1~13번을 사용한다.

## 5. 신규 랜딩 비교안 `/v2` (2026-10-02)

기존 `/`의 이야기와 연출을 유지하면서 C·D·E·H를 각각 7·8·9·12번으로 통합했다. `/v2`는 같은 다크·골드·페이퍼 톤을 사용하는 별도 미리보기이며, 검색 색인을 막았다. 신규안은 코드 주석 A~I로 구분한다.

| 참조 | 화면 |
|---|---|
| A | 히어로: 배운 코딩이 작품으로, 작품이 우리 학원의 포트폴리오로 |
| B | 실제 작품: 나나쌤 공개 허용 예시와 작품 링크 |
| C | 한 달 수업: 과제 자료와 4주 운영 예시 |
| D | 선생님의 역할·지원과 외부 제작 도구 안내 |
| E | 상담에서 보여 주는 작품·공개 프로필 |
| F | 기존 `PROOF`와 집계 기준을 재사용한 운영 기록 |
| G | 기존 `START`를 재사용한 가격·파일럿·코칭 및 도입 절차 |
| H | 도입 전 FAQ: 제작 도구·공개 범위·동의·이용 종료 |
| I | 최종 파일럿 신청과 기존 랜딩 비교 링크 |

확인되지 않은 학생 학년·제작 기간, 원생 증감, 1인 평균 수치는 추가하지 않는다. 개발일지를 공개 프로필로 설명하지 않으며, 외부 도구 이용료와 연수 참여 조건은 구분해서 안내한다.

## 6. v2 선택 구간의 v1 통합 (2026-10-02)

- 7번은 기존 `PhoneVideo`를 유지하고 과제 193개·매달 추천 과제 5개·4주 운영 예시를 함께 보여 준다. 6번의 중복 과제 수량·5단계 카드는 제거했다.
- 8번은 워크숍 참고 생성 이미지와 선생님의 역할·코칭·외부 제작 도구 안내를, 9번은 공개 프로필과 상담 결과물을 보여 준다.
- 12번 FAQ는 도입 조건(11번)과 최종 신청(13번) 사이에 배치했다.
- 선택 구간은 `src/components/landing/classroom-sections.tsx`와 `landing-v2.css`를 공유한다. `/v2`의 C는 과제 화면, `/`의 7번은 기존 활동 영상을 사용한다.
- 색상 흐름: 7 다크 → 8·9 페이퍼 → 10 다크 → 11·12 페이퍼 → 13 다크.

- 11번은 `/v2`의 G(06 — START SMALL) 디자인을 공유한다. 파일럿은 다크·골드 카드와 신청 버튼으로 강조하고, 가격·코칭은 밝은 카드로 배치한다. 4단계 도입 절차와 10명 이용료 예시도 함께 표시한다.

- 공유 구간의 `02·03·04·06·07 — 영문 제목` eyebrow는 제거했다. 8번 이미지는 기존 워크숍의 공간 구성을 참고한 가상 성인 인물의 생성 이미지 `public/about/workshop-generated.webp`를 사용한다. 기존 브랜드 스토리의 실사 워크숍 사진은 별도 자산이다.
