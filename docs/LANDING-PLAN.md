# 랜딩 페이지 구성 기획 v2

정리일: 2026-09-29 · v1(한 학원의 한 달 달력 메타포)은 폐기하고 이 문서로 덮어썼다.

섹션 현황 확인일: 2026-09-30. 아래 번호는 현재 코드 주석 기준이며, 앞으로 랜딩 페이지를 논의할 때 사용하는 참조 번호다. 화면에 표시되는 번호나 HTML의 순번은 아니다.

## 0. 방향

**관객:** 코딩학원 원장님(교육 제공자). 학부모가 아니다.
**원장님의 어려움:** 한 명을 1년, 3년 지켜야 하는데 커리큘럼이 6개월이면 바닥난다. AI 시대에 무엇을 가르쳐야 할지 모른다. 학부모는 "AI가 다 해 주는데 왜 배워요?"라고 묻는다.
**원하는 반응:** "우리 학원 얘기다" → "그 교육은 이런 모양이구나" → "4주만 써 보자."

## 1. 이야기 뼈대 — 선언 → 왜 → 그래서 → 어떻게 → 어디서

| 주제 | 내용 |
|---|---|
| 주제1 | 학생 한 명이 스타트업이 되는 교육이 AI 시대에 필요한 교육이다 |
| 주제2 | 무한한 지식의 시대를 지나 무한 실행의 시대로 진입하고 있다 |
| 주제3 | 교육이 시대의 흐름에 발맞추어 변해야만 한다 |
| 결론 | 렛츠코딩 라운지 플랫폼에서 실현 가능하다 |

주제1은 히어로에서 선언하고, 시대 변화 → 성장 과정 → 라운지 공간 → 사이클 → 기능 → 활동 → 실측 → 도입 → 마지막 제안으로 이어진다.

## 2. 현재 섹션 구성 (`src/app/page.tsx`)

2026-09-30 `MODIFY.md` 요청을 반영하여 화면 순서대로 **1~10번**을 사용한다. 과거 문서의 4번은 현재 3번, 5-2는 5번, 5-3은 6번, 5-4는 7번, 6~8번은 8~10번이다.

| 번호 | 내용 | 헤드라인 |
|---|---|---|
| 1 | 히어로 | 학생 한 명이, 스타트업이 됩니다. |
| 2 | 시대 | 무한한 지식의 시대를 지나, 무한한 실행의 시대로 나아갑니다. |
| 3 | 성장 과정 | 만들고 공유하기, 성장하고 기록하기 |
| 4 | 라운지 공간 | 공동체가 함께 즐겁게 소통할 수 있는 놀이터같은 공간 |
| 5 | 세 축의 사이클 | 세가지 축이 서로 탄탄하게 연결되어 작품제작 활동이 역량 준비와 경제교육으로 이어지게 됩니다. |
| 6 | 기능 | 렛츠코딩라운지 기능소개 |
| 7 | 활동 | 문법 대신, 자기 작품을 만듭니다. |
| 8 | 운영 수치 | 지금 이순간도 새로운 작품들이 등록되고 있습니다. |
| 9 | 시작 | 반 하나로 충분합니다. (변경 없음) |
| 10 | 마지막 제안 | 다음 스타트업의 탄생을 기다립니다. |

- 번호는 화면의 콘텐츠 구간 기준이다. HTML `<section>` 개수와는 다르며, 3번은 소개와 스크롤 장면으로 나뉘고 4~6번은 하나의 `<section>` 안에 있다.
- 요청한 줄바꿈은 `<br />`로 명시했다. 문구 기준은 루트 `MODIFY.md`다.
- 7번 영상은 원본 `public/landing/video/lounge-shorts.mp4`의 17~21초를 별도 4초 무음 영상 `lounge-activity-loop.mp4`로 편집했다. 원본은 보존한다.
- 8번 숫자는 기준일이 있는 실측을 유지한다. 화면 진입 시 집계값의 십 단위부터 시작해 앞자리는 고정하고 일의 자리만 아래에서 위로 올라오는 세로 롤링으로 집계값까지 올라간 뒤 시작 숫자로 자연스럽게 이어져 무한 반복한다(220 → 224건, 40 → 45명, 8,680 → 8,689회, 410 → 419개). 실시간 데이터로 가장하거나 집계값을 임의로 늘리지 않는다. 동작 줄이기 설정에서는 애니메이션 없이 집계값을 표시한다.
- 2번의 학부모 질문과 개별 채용 사례는 기존처럼 숨겨 두었다.

확인 소스: [랜딩 페이지](../src/app/page.tsx), [스크롤 장면](../src/components/landing/scroll-scene.tsx), [숫자 연출](../src/components/landing/reveal-observer.tsx).

이전 기획 문서에 나오는 번호는 작성 당시 번호다. 앞으로의 대화에서는 위 1~10번을 사용한다.
