# [그림 2] 라운지 경제 모델 — 이미지 구성안

KIE.AI로 생성하기 전의 구성안이다. 내용은 라운지 저장소(`yudanah/letscoding_lounge`, 2026-09-23 기준)의 실제 코드 동작을 따른다. 근거는 [ECONOMY-RESEARCH.md](./ECONOMY-RESEARCH.md)에 있다.

## 1. 메시지

**한 문장:** 작품이 상품이 되고, 친구들이 시장이 되고, 루캣이 가치의 신호가 된다.

**원칙 한 줄 (그림 안에 넣는다):**
> 가장 큰 루캣은 과제가 아니라, 친구들이 내 작품에 보낸 관심에서 나온다.

**쓰지 않는 말:** "위험", "손실". 현재 주가는 떨어지지 않으므로 실제 동작과 맞지 않는다. 대신 "안목"(어떤 작품이 주목받을지 알아보기)을 쓴다.

## 2. 그림 1과의 관계

- [그림 1] 라운지 확장 모델의 3단계 "참여(댓글·투자)"를 확대해 보여 주는 그림이다.
- 한 세트로 보이도록 비주얼 언어를 그대로 가져온다.
  - 파스텔 반투명 카드
  - 번호 원
  - 굵은 제목에 얇은 부제
  - 흰 내부 카드와 3D 아이콘
  - 왼쪽 세로 축
  - 오른쪽 점선 순환 화살표
  - 하단 캡션
- 흐름도 그림 1처럼 **세로 4단**으로 한다. 원형 배치는 이미지 모델이 한글 라벨을 자주 망가뜨려서 쓰지 않는다.

## 3. 레이아웃

비율 3:4 세로 (그림 1과 같은 약 1086×1448).

```
         ┌────────────────────────────────────────────┐
 기본    │ ①  벌다 — 기본 소득                  (작게)│
 소득    │    [출석·과제] → [로그인]                   │ ◀┐
  │      └────────────────────────────────────────────┘  ┆
  │                        ▼                              ┆
  │      ┌────────────────────────────────────────────┐  ┆
 루캣의  │ ②  만든다 — 생산                            │ ◀┤ 다음
 흐름    │    [작품 공개=상장] [스티커 납품] [유료 게임] │  ┆ 작품
  │      └────────────────────────────────────────────┘  ┆
  │                        ▼                              ┆
  │      ┌────────────────────────────────────────────┐  ┆
  │      │ ③  시장 — 친구들이 가치를 매긴다   (가장 큼)│  ┆
  │      │    [관심] → [투자] → [수익]                 │  ┆
  │      │    ★ 원칙 한 줄                             │  ┆
  ▼      └────────────────────────────────────────────┘  ┆
         ┌────────────────────────────────────────────┐  ┆
 선택    │ ④  쓰고 굴린다 — 선택                        │ ─┘
         │    [광고] [다른 작품에 투자] [이자]          │
         └────────────────────────────────────────────┘
   [그림 2] 라운지 경제 모델. …(캡션)
```

- **크기 위계:** ③ 시장 > ② 만든다 = ④ 쓰고 굴린다 > ① 벌다. ①을 가장 작게 두어 "과제 보상은 기본일 뿐"이라는 무게를 시각적으로 준다.
- **점선 화살표:** ④에서 나와 ②로 돌아간다. 라벨은 "다음 작품".
- **색:** 그림 1과 겹치지 않게 차례를 바꾼다. ① 회청색, ② 파랑, ③ 주황·황금(루캣 코인 색), ④ 초록.

## 4. 들어갈 글자 (확정 텍스트)

이미지 모델은 긴 한글을 자주 틀리게 그린다. 그래서 글자는 이 목록으로 제한하고, 숫자는 넣지 않는다.

|---|---|---|---|
| ① | 벌다 — 기본 소득 | 출석 · 과제 · 로그인 | 출석·과제 / 선생님 지급 → 로그인 / 매일 보너스 |
| ② | 만든다 — 생산 | 작품이 상품이 된다 | 작품 공개 / 주식 상장 · 스티커 / 창작 납품 · 게임 / 유료 플레이 |
| ③ | 시장 — 친구들이 가치를 매긴다 | 관심 · 투자 · 수익 | 관심 / 조회 · 좋아요 → 투자 / 작품 주식 → 수익 / 주가 · 판매 · 플레이 |

### 아이콘

| 카드 | 아이콘 |
|---|---|
| 출석·과제 | 체크 표시가 있는 클립보드 |
| 로그인 | 달력 |
| 작품 공개 | 로켓, 또는 상승 그래프가 붙은 브라우저 창 |
| 스티커 | 반짝이는 스티커 |
| 게임 | 게임패드 |
| 관심 | 눈 + 하트 |
| 투자 | 코인이 쌓인 모양 + 위쪽 화살표 |
| 수익 | 금색 코인 주머니 |
| 광고 | 메가폰 |
| 다른 작품 투자 | 친구 작품 카드에 코인 |
| 이자 | 저금통 |

루캣 코인은 금색 원형 코인에 고양이 얼굴 실루엣으로 통일한다.

## 5. 각 요소의 근거 (내부 참고용, 그림에는 넣지 않음)

| 요소 | 실제 동작 | 학술 근거 |
|---|---|---|
| ① 출석·과제 | 선생님이 수동 지급하는 기관 승인 발행 | — (의도적으로 작게) |
| ② 작품 공개 = 상장 | 공개 시 트리거로 주식 생성, 시작 주가 1루캣 | Huber et al. 2014 (창업 교육) |
| ② 스티커 | 납품 → 검토 승인 → 판매 시 창작자 70% | Mini-Society (학생 주도 생산) |
| ② 게임 | 플레이값 1~5루캣, 100루캣 이상 정산, 수수료 20% | Mini-Society |
| ③ 관심 | 라운지 구성원의 조회 1회당 1루캣(하루 최대 500), 조회·좋아요가 주가를 올림 | Deci et al. 1999 (긍정 피드백은 동기를 높임) |
| ③ 투자 | 소수 조각 거래, 거래 수수료 0.1루캣, 새 투자자가 생기면 주가 상승 | My Classroom Economy (체험식 금융) |
| ④ 광고 | 맨 위로 30, 광고 슬롯 10/30/100 (소각) | 기회비용 |
| ④ 이자 | 지갑 + 주식 평가액의 월 0.1% | Kaiser & Menkhoff 2020 |
