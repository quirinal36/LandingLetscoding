# 프로젝트 구조 그래프

2026-10-22 현재 작업 트리 기준으로 다시 빌드했습니다.

- `graph.html`: 브라우저에서 여는 인터랙티브 그래프
- `graph.json`: 질의에 사용하는 그래프 데이터
- `GRAPH_REPORT.md`: 중심 항목, 커뮤니티, 연결 분석 및 범위
- `health.json`: 추출 데이터 무결성 진단

## 분석 범위

코드 98개와 문서 71개를 분석했습니다. 사용자 선택에 따라 이미지·PDF·영상·오디오는 제외했습니다. HTML 내 base64 데이터는 의미 분석에서 생략했습니다. 코드 구조는 AST, 문서 관계는 현재 Codex 세션의 병렬 에이전트로 추출했으며 문서 17개는 기존 캐시를 재사용했습니다. JSON 설정·데이터 12개에서는 AST 노드가 생성되지 않았습니다.

문서에는 기획·초안·이전 자료가 포함됩니다. 블로그의 현재 원본은 `landing.blog_posts`이며 이 그래프는 실제 DB 본문을 조회하지 않았습니다. 실제 변경 전 현재 소스를 확인하세요.

## 토큰 집계

AST는 LLM 토큰을 사용하지 않습니다. 문서 추출은 호스트 세션에서 진행해 정확한 토큰 수를 계측하지 못했습니다. 보고서와 `cost.json`의 0은 미계측 값이며 실제 세션 사용량이 0이라는 뜻이 아닙니다.

## 사용

프로젝트 루트에서 `graphify query "질문"`으로 질의합니다. 코드나 문서를 수정한 뒤에는 그래프를 갱신해야 합니다. 다음 전체 스캔에는 제외한 미디어도 감지될 수 있으므로 범위를 확인하세요.

정리 메모: 중복 `_workspace/*/final.md`는 `docs/articles/drafts/`와 본문이 같음을 확인한 뒤 삭제하고, 그래프의 출처 경로를 보존한 원고로 연결했습니다.
