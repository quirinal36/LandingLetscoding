# 프로젝트 구조 그래프

2026-09-30 블로그 DB 연결·관리자 로그인 구현 전에 만든 graphify 결과입니다. 이후 추가된 블로그 기능과 문서·이미지 경로 정리는 아직 그래프에 반영되지 않았습니다. 현재 경로는 루트 README의 문서 목록을 참고하세요.

- `graph.html`: 브라우저에서 여는 인터랙티브 그래프
- `graph.json`: 질의에 사용하는 그래프 데이터
- `GRAPH_REPORT.md`: 중심 항목, 커뮤니티, 연결 분석
- `health.json`: 추출 데이터 무결성 진단

## 분석 범위

코드 59개와 문서 33개를 대상으로 분석했습니다. 이미지 118개와 영상 및 오디오 3개는 이번 빌드에서 제외했습니다. HTML에 포함된 base64 데이터는 문서 의미 분석에서 생략했습니다.

코드 구조는 AST로 추출하고 문서의 개념과 관계는 현재 Codex 세션의 병렬 에이전트로 추출했습니다. JSON 설정 및 데이터 파일 3개(`.claude/settings.json`, `motion/reel/music.json`, `src/lib/works.json`)에서는 AST 노드가 생성되지 않았습니다.

문서의 기획과 현재 구현이 다를 수 있으므로 실제 변경 전 소스를 확인합니다. 문서 간 의미 연결 중 추론은 `INFERRED`로 표시합니다.

## 토큰 집계

AST는 LLM 토큰을 사용하지 않습니다. 문서 추출은 호스트 세션에서 진행해 정확한 토큰 수를 계측하지 못했습니다. 보고서와 `cost.json`의 0은 도구 집계값이며 실제 세션 사용량이 0이라는 뜻이 아닙니다.

## 사용

프로젝트 루트에서 `graphify query "질문"`으로 질의합니다. 코드나 문서를 수정한 뒤에는 그래프를 갱신해야 합니다. 기본 전체 스캔에는 이번에 제외한 미디어도 감지될 수 있으므로 갱신할 때 분석 범위를 확인합니다.
