# 8쪽 「AI가 대신 코딩해주는 시대」 영상 두 편

발표 덱(`output/expo-talk/index.html`) 8쪽에 나란히 놓이는 반복 영상이다. 두 편 모두 12초이고, 쪽에 들어오면 함께 처음부터 돌기 시작해 끝나면 다시 돈다. 마지막 0.6초에 화면을 바탕색으로 덮었다가 첫 장면으로 돌아오므로 이음매가 보이지 않는다.

- `human-typing.html` → `reel/human-typing.mp4` (덱 설명 「사람이 직접 입력하는 코드」): 어두운 편집기에서 사람이 변수·반복문·조건문을 한 글자씩 친다. 괄호 하나를 빠뜨려 빨간 오류가 뜨고, 그 괄호를 찾아 넣어야 오류가 사라진다. 문법을 외워 치던 코딩이 어려웠다는 말을 화면이 보여 준다.
- `ai-code-diff.html` → `reel/ai-code-diff.mp4` (덱 설명 「AI가 작성하고 수정하는 코드」): 렛츠코딩 스튜디오처럼 생긴 밝은 화면. 학생이 "파도가 오면 소리가 나게 해 줘", "바다 색을 더 파랗게 바꿔 줘"라고 말하면 AI 도우미 LECO가 코드에 줄을 넣고(초록) 빼고(빨강) 고친다. 미리보기의 바다 색도 바뀐다. 발표자가 8쪽에서 하는 말("기능을 넣고 싶으면 AI에게 설명하고, 화면 색이 마음에 안 들면 바꿔 달라고 한다")과 맞춘 것이다.

코드는 실제로 읽히는 자바스크립트로 쓴다. 이전 영상은 생성 영상이라 "frulnction" 같은 뜻 없는 글자가 보였다.

## Typography

- 한글: Pretendard Variable. 덱 본문(Apple SD Gothic Neo)과 결이 비슷하고, 렌더러가 확실히 쓰도록 이 영상에 나오는 글자가 든 조각만 `fonts/`에 담았다(원본은 `public/fonts/pretendard`). 글자를 바꾸면 조각을 다시 골라야 할 수 있다.
- 코드: JetBrains Mono (HyperFrames가 자동으로 넣는다)

## What NOT to Do

- 뜻 없는 코드나 깨진 글자를 쓰지 않는다. 화면의 코드는 그대로 실행될 수 있어야 한다.
- 덱 카드 안에서 절반 크기로 보이므로 코드 36px, 한글 30px보다 작게 쓰지 않는다.
- 끝 장면과 첫 장면을 다르게 두지 않는다(반복할 때 튄다).
- 실제 제품에 없는 메뉴나 단추를 지어내지 않는다. 오른쪽 화면의 이름(Let's Coding Studio, AI 도우미 LECO, 라운지에 게시하기, script.js, 미리보기)은 11쪽 스튜디오 화면에 있는 것만 쓴다.
