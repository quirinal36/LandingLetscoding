# 박람회 부스 디자인

`index.html`에서 선택한 통합안 v4와 공통 평면도를 확인한다. 선택 시안은 HTML을 직접 표시하므로 수정 후 브라우저를 새로고침해 확인한다. PNG 미리보기는 매 수정마다 갱신하지 않는다. 기존 A/B/C는 접힌 비교 항목에 보존했다. 각 방향에는 1600×1050 비교 보드, 950:2380 비율의 벽면 9장 전개, 950:660 데스크 디자인이 있다. 실제 제품 화면은 저장소 기존 자산을 참조한다.

저장소 루트에서 `python3 -m http.server 8769 --bind 127.0.0.1` 실행 후 `http://127.0.0.1:8769/output/expo-booth/`를 연다. 이 폴더만 옮기면 상대경로 이미지·폰트가 끊기므로 저장소 구조를 유지한다. PNG 미리보기는 `previews/`에 보관한다.

## 단계와 범위

사용자가 C의 색감과 B의 설명 방식을 결합하도록 선택했다(`direction-approved.md`). `design-demos/selected-v4.html`이 현재 통합 디자인 원본이며 9패널과 데스크에 선택 방향을 적용했다. 출력 PDF 및 TV용 설명 자료/영상은 아직 만들지 않았다. 가구 실측과 인쇄 해상도·업체 여백·색상 조건을 확인한 뒤 생산용 파일을 확정한다. 사이트 코드·DB·기존 인쇄물은 변경하지 않았다.

확정: 교사 대상, 3×3m, 벽면9장, 데스크, 태블릿2대, PC4대, 65인치 TV는 사용자 거치대 설치 및 PC 확장 모니터 사용.

미확정: 실제 내부 유효 치수, 가구·거치대 실측, 모니터·본체 규격, TV 설치 높이, 의자·관람객 점유와 전원/케이블 배선. 배치도는 임시 치수이며 설치 적합성 또는 동시 체험 인원을 확정하는 도면이 아니다.

## 검수 기록 · 2026-11-08

Aside 실제 브라우저에서 세 방향의 첫 보드가 모두 1600×1050이고 이미지 누락 및 페이지 가로 넘침이 없음을 확인했다. 정면·전개도·공통 배치도를 캡처해 육안 검수했고, A 설명의 꼬리말 겹침 및 A/C 전개도 제목 스타일 충돌을 수정 후 재캡처했다. 미리보기는 `previews/A-gallery.png`, `B-studio.png`, `C-lounge.png`, 각 `-unfold.png`, `overview.png`, `layout.png`에 있다. 사이트 코드를 수정하지 않아 Next 빌드/앱 테스트는 실행하지 않았다.

## 통합안 v1 · 2026-11-08

C의 코랄 후면과 보라·남색·밝은 보라 측면 색상을 B의 요청 → 실행 → 수정 설명 구조에 적용했다. 원본 A/B/C는 보존했다. 브라우저에서 9패널 개수, 각 950:2380 비율, 데스크 950:660 비율, 이미지 로딩, 1600×1050 보드 및 가로 넘침을 확인했다. 최종 캡처는 `previews/selected-v1.png`와 `previews/selected-v1-unfold.png`. TV와 겹치지 않게 후면 로고를 아래로 옮기고 흰 바탕으로 원래 로고 색을 보존했다.

## 통합안 v2 · 후면 메시지 개편

사용자 요청에 따라 통로에서 AI 활용·바이브코딩 플랫폼임을 즉시 알아볼 수 있도록 후면을 수정했다. B1은 남색 바탕의 큰 「AI 활용 / 바이브코딩」, B2는 「게임도, / 학습 도구도.」, B3는 「우리 반이 / 만들어요.」다. 바이브코딩을 모르는 관람객에게는 B1 옆 설명으로 말로 요청하고 직접 실행하며 작품을 만드는 방식임을 알린다. 기존 요청·실행·수정 설명은 측면에 유지한다. TV 위에 큰 제목, TV 양옆에 쉬운 보조 설명을 배치했다. v1은 보존한다.

검수: 후면 제목 3개가 모두 TV 상단보다 위에 있고 줄 넘침이 없으며, 양옆 설명이 TV와 겹치지 않음을 브라우저에서 확인했다. 9패널·데스크 비율과 이미지 로딩도 재확인했다. 캡처: `previews/selected-v2.png`, `previews/selected-v2-unfold.png`. 실제 통로 거리에서의 가독성은 아직 현장 검증 전이다.

## 통합안 v3 · 확정 문구 적용

사용자가 추천 문구 적용을 지시했다. 가운데 윗문구는 「AI와 함께 만드는」, 제목은 「코딩을 몰라도, / 아이디어가 있다면」이다. 오른쪽 윗문구는 「미래교육을 만나보세요.」, 제목은 「나만의 세상을 / 만들 수 있습니다.」다. 후면 정면과 9패널 전개도에 동일하게 적용했다. 긴 두 제목은 같은 글자 크기로 조정해 지정한 두 줄을 유지한다. v2는 보존한다. 최신 캡처는 `previews/selected-v3.png`, `previews/selected-v3-unfold.png`.

검수: 후면 입면과 전개도 양쪽에 확정 문구가 동일하게 표시됨을 확인했다. 후면 제목의 가로 넘침 및 TV 가림 없음, 이미지 로딩과 9패널/데스크 비율을 브라우저에서 재검증하고 캡처했다.

## 통합안 v4 · 후면 제목 확대

사용자 요청으로 B2·B3의 제목 크기를 B1과 동일한 15.6cqw로 확대했다(기존 10.5cqw 대비 약49% 확대). 문구를 보존하면서 각각 네 줄로 나누었다. 후면 TV·거치대·기기 라벨과 전개도 TV 점유 표시를 함께 낮췄고, 제목 아래 선·오른쪽 보조 설명·로고도 겹치지 않게 조정했다. 실제 TV 높이는 사용자 거치대에서 조절한다. v3는 보존한다.

검수: 후면 세 제목의 실제 렌더 글자 크기가 모두 39.936px로 동일함을 확인했다. 정면·전개도 문구 일치, 가로 넘침 및 제목/설명의 TV 가림 없음, 이미지 로딩과 패널·데스크 비율을 확인하고 `previews/selected-v4.png`, `previews/selected-v4-unfold.png`로 캡처했다.

### v4 가운데 제목 줄바꿈 수정

가운데 제목만 사용자 지정대로 「코딩을몰라도, / 아이디어가 / 있다면」의 세 줄로 수정하고 13.8cqw로 줄였다. 정면과 전개도에 동일하게 적용했다. 나머지 제목과 TV 위치는 유지했다.

### v4 오른쪽 제목 줄바꿈 수정

오른쪽 제목은 「나만의 세상을 / 만들 수 / 있습니다.」의 세 줄이다. 중복된 「세상을」을 삭제하고 띄어쓰기를 바로잡았다. 글자 크기는 13.3cqw이며 정면과 전개도에 동일하게 적용했다.
