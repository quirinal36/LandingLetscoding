# 렛츠코딩 라운지 박람회 부스 — 비교 시안 브리프

## 확정 정보
사용자는 실제 박람회 부스 내부 인쇄 디자인을 의뢰했다. 대상은 교사이며 서비스는 렛츠코딩 라운지와 Studio다. 전달할 핵심은 학생의 아이디어가 실행되는 작품이 되고, 학생은 AI의 결과를 확인하고 수정하며, 교사는 질문과 피드백으로 이 과정을 지도한다는 것이다. 재미있는 완성 작품만 보여주는 부스보다 교사가 자기 교실에 적용할 모습을 이해하는 부스여야 한다. 실제 공개 사용이 허용된 나나쌤 작품 예시를 활용하되 학생 성과라고 잘못 표기하지 않는다. 확정되지 않은 학습 효과, 무료 조건, 요금, 제작 시간, 자동 평가 기능을 주장하지 않는다.

사용자 도면은 가로 3000 × 깊이 3000mm, 벽체 2500mm, 상부 간판 1000mm, 총 높이 3500mm다. 내부 출력은 한 장 950 × 2380mm이며 왼쪽 L1-L3, 뒤쪽 B1-B3, 오른쪽 R1-R3의 9장을 가정한다. 벽마다 2850mm 출력 폭과 3000mm 구조 폭은 다르므로 패널 사이 프레임 및 잔여 여백은 실측해야 한다. 데스크 출력 전면은 950 × 660mm다. 전면은 개방이며 안내 데스크는 앞 오른쪽을 기본으로 한다. 태블릿은 2대, PC는 4대이며 사용자가 별도 책상을 가져온다. 65인치 TV도 사용자가 거치대를 가져와 설치한다. TV는 PC의 확장 모니터이므로 제품 설명 화면과 시연 화면을 전환할 수 있다. 벽체에 TV를 고정한다고 가정하지 않는다.

현재 배치는 중앙 후면 TV, 좌측 벽 PC 2대, 우측 벽 PC 2대, 입구 왼쪽 태블릿 2대, 입구 오른쪽 데스크다. 책상 크기·TV 거치대 바닥 크기·높이·전원 위치는 미확정이다. 렌더는 디자인 검토용으로 명시하고 시공 가능성을 보증하지 않는다. 실제 6인 동시 체험·의자 배치와 이동 폭은 검증하지 않은 상태다. TV 활성 화면은 16:9 약 1440 × 810mm로 표현하되 베젤과 거치대는 가정이다. 화면 하단 높이 1050mm, 상단 1860mm를 임시 기준으로 사용할 수 있다. 뒷벽 글자는 TV에 가려지지 않도록 1900mm 이상 또는 화면 옆으로 배치한다. 가구로 가려지는 벽 하부에 필수 정보를 넣지 않는다.

## 실제 브랜드 자산과 콘텐츠
로고는 output/ai-edu-expo/assets/logo-mark.png. 로고의 색·비율을 보존한다. 기존 간판 output/ai-edu-expo/signboard.html의 브랜드 색은 짙은 남색 #0b0a24, 보라 #7439f1, 인디고 #3c34c5, 코랄 #fc6a77, 밝은 보라 #cfc9ff다. 흰색과 기존 본문 #1b2333, 보조 #55607a도 사용 가능하다. 폰트는 prototypes/brochure/fonts.css의 Pretendard Variable. 인쇄 면은 단색, 그림자/장식용 그라디언트는 피한다. 기존 간판과 같은 브랜드로 보여야 하지만 각 방향은 구성과 메시지 표현에서 뚜렷하게 달라야 한다.

실제 제품 화면: public/landing/studio-workspace.png, works-grid.jpg, project-report.png. 작품은 public/landing/works/pixel-art-maker.webp, ten-pang.webp, english.webp, image-editor.webp, songpyeon.webp, absolute-pitch.webp. 모든 경로는 repo root 기준. 원본 확인 없는 추가 학생 작품을 사용하지 않는다. 화면을 모사한 가짜 제품 UI를 만들지 않는다. 실제 화면을 직접 이미지로 사용한다. 생성 사진·로봇·미래 도시 같은 장식은 쓰지 않는다. 로고는 반드시 실제 파일로 렌더한다. 그림이 의미를 담당하고 텍스트는 짧게 작성한다.

## 출력물의 역할
각 방향은 비교 가능한 동일한 크기의 HTML 컨셉 보드로 제작한다. 첫 화면 .board는 정확히 1600 × 1050px이며 스크린샷 대상이다. 전체 페이지는 가로 1600px 고정, 자연스러운 세로 스크롤 가능. 첫 보드에는 방향 이름, 한 줄 컨셉, 큰 후면 정면 입면도(뒤쪽 벽 3패널, 실제 화면을 담은 TV 및 거치대와 데스크 오버레이), 대표 좌/우 패널 또는 데스크 아트워크를 구성한다. 전체를 기술 도면처럼 만들지 말고 디자인 스튜디오의 검토 보드처럼 편집한다. 단, 건축적 TV/기기/가구 박스와 치수선은 단순 도식임을 명시한다. 정면 입면은 side wall이 보이지 않는 직교도이므로 실내 전체 투시라고 부르지 않는다. 상부 간판은 기존 시안 연계 표시만 가능하며 이번 신규 출력 범위에 포함하지 않는다.

둘째 섹션 .unfold는 1600px 폭으로 9장을 모두 L1-L3 / B1-B3 / R1-R3 그룹으로 펼친다. 패널의 950:2380 비율을 정확히 보존한다. 각 패널 경계가 눈에 보여야 하고 글자가 경계를 가로지르면 안 된다. 뒤쪽 TV 점유 영역은 첫 보드에서 보이고 전개도에서는 반투명 점유 영역이나 짧은 설명으로 확인 가능하게 한다. 데스크 950:660도 정확한 비율의 아트워크를 별도로 보여준다. 세부 문안은 짧고 읽기 쉬워야 하며 제작용 라벨은 아트워크 밖에 둔다.

교사용 문안 후보: 학생의 아이디어가 작품이 되는 수업 / 말로 요청하고, 실행하고, 고쳐요 / 만들고, 공유하고, 다시 도전합니다 / 무엇을 만들까요? / 원하는 대로 작동하나요? / 무엇을 바꾸면 더 좋을까요? / 우리 수업에서는 무엇을 만들까요? / 바이브코딩 체험 · 수업 도입 상담. 학생에게 질문하는 문장과 교사에게 도입을 권하는 문장을 혼동하지 않는다. 9패널이 9개의 문장 포스터처럼 보이지 않게 세 벽의 역할을 만든다.

## 구현과 검수
새 폴더 output/expo-booth/ 밖의 파일은 수정하지 않는다. 기존 저장소에는 사용자 미커밋 변경이 많다. 각 방향 담당자는 design-demos/A-gallery.html, B-studio.html, C-lounge.html 중 자기 파일만 작성한다. CSS와 HTML은 자체 포함, 로컬 이미지·폰트는 repo 상대경로로 참조한다. 멀티파일 프로젝트이며 root에서 로컬 서버로 본다. dependency 추가나 React/Next route 변경 없이 순수 HTML/CSS. footer에 컨셉 시안 / 출력·시공용 아님과 남은 치수 확인을 넣는다. 실제 인쇄 파일로 오인되는 PDF는 만들지 않는다. 최종 선택 이전에는 전체 생산용 아트워크 및 TV 영상 제작에 진입하지 않는다. root가 통합 인덱스·배치도·스크린샷 검수를 수행한다.
