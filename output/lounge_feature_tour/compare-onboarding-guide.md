# 기능 둘러보기 영상과 온보딩 가이드 영상 비교

[기능 둘러보기 영상 목차](video-outline.md)(58분 32초)를 기존 [온보딩 가이드 영상 목차](../onboarding_guide/video-outline.md)(57분 31.5초)와 대조해, 무엇이 새로 나왔고 무엇이 빠졌으며 설명이 어떻게 바뀌었는지 정리한 문서입니다. 마지막에 가이드 페이지(`/guide`)의 세션·편 구조에 반영할 제안을 적었습니다.

## 1. 두 영상의 성격 차이

| 항목 | 온보딩 가이드 영상 | 기능 둘러보기 영상 |
| --- | --- | --- |
| 중심 흐름 | 수업 사례(구구단 스네이크) → 기관 가입 → 클래스 관리까지 전체 운영 | 학생 과제 한 바퀴 → 라운지의 활동 장치(광고·투자·배지·스티커·개발보고서) |
| 제작 방식 | 외부 도구(VS Code + AI 구독)로 만든 뒤 직접 등록하는 방식과 스튜디오 방식을 둘 다 보여 줌 | 스튜디오 한 곳에서 만들고 게시까지 끝냄. 외부 도구는 '예전 방식'으로만 언급 |
| 관리자 기능 | 기관 가입, 교사 권한, 클래스별 AI 설정, 방문 통계를 다룸 | 교사의 과제 검토만 다루고 기관·클래스 설정은 없음 |
| 요금 | 플랜별 역할과 사용량 차이를 설명 | 요금제 설명 없음. 두 달 체험 계정 제공 조건만 안내 |
| 화면 조작 | 안내자가 조작하며 설명 | 원장이 직접 조작하고 안내자가 말로 안내. 그래서 '두 번째 탭', '컨트롤+2' 같은 조작 지시가 많음 |
| 녹음 범위 | 처음부터 끝까지 | 대화 중간에서 시작. 과제 체계 설명 앞부분이 잘려 있음 |

두 영상은 겹치는 구간(과제 시작, 스튜디오 제작, 게시, 교사 검토, 투자·배지)이 있지만, 기능 둘러보기 영상은 그 겹치는 구간을 더 깊게 설명하고 라운지 쪽 기능을 훨씬 많이 다룹니다.

## 4. 설명이 바뀐 내용

같은 기능인데 설명이 달라졌거나 더 구체화된 부분입니다. 가이드 교재 본문을 쓸 때 이번 영상 쪽을 기준으로 삼는 것이 좋습니다.

| 기능 | 기존 영상 | 이번 영상 |
| --- | --- | --- |
| 작품 등록의 기본 경로 | '작품 등록' 버튼의 폼에서 등록 | 스튜디오의 '라운지에 게시하기'가 기본. 등록 폼은 외부 링크 작품과 수정용 |
| 제작 도구 | VS Code + 외부 AI 구독으로 만든 작품을 스튜디오 사례와 함께 소개 | 스튜디오만 사용. VS Code 방식은 '예전 방식'으로만 언급 |
| 랭킹 붙이기 | 준비된 요청문으로 랭킹 구현을 요청 | 같은 기능이지만 변천 과정과 미리보기 제약까지 설명 |
| 투자 수수료 | '거래 수수료 개념'으로 언급 | 0.1루캣 고정으로 확정. 학생 요청으로 낮췄다는 경위 포함 |
| 투자 가치 변동 | 지표에 따른 가치 변화 | 하락은 없고 자정마다 0.1~0.3%씩만 상승 |
| 배지 | 접속·댓글·랭킹·작품·개발일지 등 활동별 배지 | 11종의 이름과 기준, 피보나치 단계, 재평가, 색상 순서까지 구체화. 투자가 배지 조건이 완화됨 |
| 학습 모드 | 학습 모드가 있다는 소개 | 프롬프트 버튼 방식에서 모델 수준 전환 방식으로 바꿀 예정 |
| 개발일지 | 요청문으로 초안을 만들어 검토 후 등록 | 같은 방식에 더해 학습 노트, 개발보고서가 별도 기능으로 등장 |
| 공개 범위 | 언급 없음 | 목록 노출과 공개 설정이 분리되어 있고 비공개 열람 범위가 정해져 있음 |
| 과제 완료 보상 | 수행 단계에 따른 가상 재화 | 4단계 완료 시 40루캣이라는 구체 수치 |
| 추천 과제 | 처음 시작할 때 도움을 주는 목록 | 월별로 쌓이는 구조. 4월부터 운영 |

## 5. 시연 중 드러난 문제와 예정 변경

촬영 전에 해결하거나 대본에서 피해야 할 항목입니다. 기존 촬영 계획의 '촬영 전 공통 준비'에 추가합니다.

- [ ] **과제 완료 처리 버그:** 교사가 완료를 눌러도 상태가 바뀌지 않음(35:22). 수정 예정이라고 했으므로 촬영 전 확인한다.
- [ ] **미리보기에서 랭킹 미동작:** 게시 후 play 도메인에서만 동작(28:50). 대본에서 '게시 후 확인'으로 순서를 잡는다.
- [ ] **스토리 만들기 베타:** 60~70% 완성 상태(04:32). 본편에서는 빼거나 '준비 중' 표시로만 둔다.
- [ ] **학습 모드 프롬프트 개선 예정:** 버튼 방식이 바뀔 수 있으니(27:14) 학습 모드는 모델 선택 화면 기준으로 촬영한다.
- [ ] **기관 슬러그 수동 변경:** DM으로 요청하는 방식(19:47)은 교재에서는 '기관 URL 변경 요청 방법'으로 안내하고, 자동화되면 교재만 고친다.
- [ ] **가격·보상 수치:** 광고 가격, 투자 수수료, 과제 보상, 스티커 되팔기 비율은 바뀔 수 있으므로 본편 자막보다 교재 본문이나 7.1 부록에 둔다.
- [ ] **녹음 앞부분 누락:** 과제 체계 설명의 시작이 잘려 있어, 이 영상을 자료로 쓸 때는 기존 영상 2장으로 보완한다.
