## 편집과 확인

학교 담당자에게 종이로 인쇄해 전달하는 브로셔다. HTML은 편집과 화면 검토에 사용하고, 글자 크기·간격·잘림 여부는 최종 가로 A4 PDF를 기준으로 확인한다.

- 편집 원본: `index.html`. 제목·본문·기능 설명·요금제 선택 기준은 HTML 텍스트다.
- 웹: `/ai-edu-expo`. 기존 `/brochure`와 별도 자료다.
- PDF: `../pdf/letscoding-school-brochure.pdf`. 웹 다운로드 주소는 `/ai-edu-expo/pdf`다.
- 출력: 가로 A4 총 12쪽(양면 인쇄 시 종이 6장), 짧은 쪽 넘김. 화면 최대 폭 1200px이며 모바일에서는 본문을 세로로 재배치한다.
- 원본 보관: `index-original.html`, `source-text.json`, `assets/image1.png`~`image7.png`. `source-text.json`은 PPTX 추출 기록이므로 새 문구에 맞춰 덮어쓰지 않는다. 원본의 상세 요금표 `assets/image7.png`는 별도 자료로 남겼다.

라우트는 HTML 원본과 폰트를 읽고, 제품 이미지에는 기존 `public/landing/` 자산을 사용한다. 수정 후 배포하려면 다시 빌드한다. PDF도 HTML 수정 후 재출력한다.

### CMYK 인쇄용 PDF

사방 3mm 도련을 요청한 인쇄소에 전달할 파일은 `../pdf/letscoding-school-brochure-cmyk-bleed-3mm.pdf`다. 기존 `../pdf/letscoding-school-brochure-cmyk.pdf`는 도련 없는 A4본으로 보존한다. 두 CMYK본은 Chrome의 RGB 출력을 Ghostscript로 PDF/X-4로 변환한 것으로, 모든 색은 DeviceCMYK·DeviceGray이고 출력 의도는 Japan Color 2001 Coated다. 글자는 벡터로 유지되며 이미지는 다운샘플 없이 무손실(Flate)로 담는다. 도련 없는 기존 CMYK본은 아래 명령으로 다시 만든다.

```sh
sh output/ai-edu-expo/export-cmyk.sh                        # PDF/X-4 (기본)
PDFX=1 OUT=/tmp/x1a.pdf sh output/ai-edu-expo/export-cmyk.sh  # PDF/X-1a가 필요한 인쇄소용
```

필요한 도구는 Ghostscript(`brew install ghostscript`), python3와 PyMuPDF, 그리고 `~/Library/ColorSync/Profiles/JapanColor2001Coated.icc`다. ICC 파일은 Adobe ICC 프로파일 end-user 배포본에서 설치하며 재배포 제한이 있어 저장소에 넣지 않는다. 스크립트는 PDF/X가 금지하는 링크 주석을 제거한 뒤 변환하고, 끝에 RGB 색공간이 남지 않았는지와 출력 의도가 있는지 검사한다. PDF/X-1a는 투명도를 허용하지 않아 3·6·7쪽이 720dpi 전면 래스터로 평탄화되므로 인쇄소가 요구할 때만 쓴다.

2026-11-17 인쇄소의 요청에 맞춰 3mm 도련본을 추가했다. 총 12쪽, 완성 크기(TrimBox)는 가로 A4 297×210mm, 도련 포함 크기(MediaBox·BleedBox)는 303×216mm다. 재단 표시는 넣지 않는다. `prepare-bleed.js`가 A4 본문 크기와 위치를 유지한 채 각 쪽의 배경을 바깥 3mm까지 확장하고, 1쪽 사진도 위·아래·오른쪽 도련까지 채운다. 표지 사진은 높이에 맞춰 약간 확대되어 재단 후 보이는 범위가 조금 달라진다. 5·12쪽의 어두운 배경도 도련 끝까지 이어진다.

```sh
EXPO_BLEED=3 EXPO_PLAYWRIGHT=/path/to/playwright EXPO_CHROME=/path/to/chrome node output/ai-edu-expo/export.cjs
EXPO_BLEED=3 SRC=tmp/pdfs/letscoding-school-brochure-bleed-rgb.pdf OUT=output/pdf/letscoding-school-brochure-cmyk-bleed-3mm.pdf sh output/ai-edu-expo/export-cmyk.sh
```

Aside에서 출력할 때도 print media를 적용하고 이미지·폰트 로딩이 끝난 뒤 `prepare-bleed.js`를 실행해 중간 RGB PDF를 만든다. Chromium의 종이 크기 반올림에 대비해 중간 파일은 약간 큰 용지로 출력하며, CMYK 변환 전에 정확한 303×216mm 영역만 크기 변경 없이 가져오고 TrimBox·BleedBox를 지정한다. 스크립트는 배경 확장 전의 A4 PDF를 입력하면 중단한다. 최종 파일의 12쪽 본문, 벡터 글자, CMYK 색공간, 페이지 박스, 1·5·12쪽 가장자리와 전체 페이지 렌더링을 확인했다. 본문 수정 시 일반 RGB·CMYK PDF와 도련본을 함께 다시 출력한다.

HTML 상단의 `3mm 재단 가이드`로 화면용 가이드선을 켜고 끈다(기본 켜짐). 창 너비 1240px 이상에서 A4 완성 크기인 페이지 경계는 분홍 실선, 바깥 3mm 도련 범위는 분홍 점선, 안쪽 3mm 안전영역은 파란 점선으로 표시한다. 1200px 페이지 폭을 297mm로 환산하므로 3mm 간격은 약 12.12px이다. 반응형으로 재배치되는 작은 화면에서는 실제 판형과 혼동하지 않도록 가이드를 숨긴다. 가이드선은 인쇄와 PDF 출력에서 제외되며, 배경 확장이나 PDF의 실제 도련 추가는 하지 않는다.

## 검증과 재출력

```sh
node output/ai-edu-expo/check.mjs
EXPO_PLAYWRIGHT=/path/to/playwright EXPO_CHROME=/path/to/chrome node output/ai-edu-expo/export.cjs
```

서버 응답 검사: `node output/ai-edu-expo/check.mjs http://127.0.0.1:3100/ai-edu-expo`.

브라우저 검사에도 `EXPO_URL=http://127.0.0.1:3100/ai-edu-expo`를 추가하면 웹의 인쇄 버튼과 PDF 응답까지 확인한다. PDF 출력 후에는 실제 페이지 수와 렌더링을 함께 확인한다. 검증용 페이지 PNG는 시스템 임시 폴더 `ai-edu-expo-revised/`에 저장한다.

## 교육철학과 세 가지 축 추가

2026년 10월 12일 사용자 요청에 따라 12쪽 구성을 유지하면서 교육철학과 세 가지 축을 보강했다. 당시 구성에서는 3쪽과 8쪽에 배치했다. 현재 3쪽은 아래의 작동 구조로 대체했다.

- 3쪽: 나의 창작·공개(Papert의 constructionism), 동료의 피드백·수정(Vygotsky의 사회적 구성주의), 구경·참여·기여(Lave와 Wenger의 실천공동체), 성찰과 포트폴리오를 통한 다음 작품의 순환. 블룸 2001 개정 분류체계는 보고서·루브릭으로 학습을 살펴보는 기준으로 구분한다.

### 벽당 2장 안 (2026-11-16)

사용자 요청으로 벽 한 면을 2장(장당 1,425×2,380mm, 같은 폭 가정, 이음선 x=1,425. 2026-11-17 장당 1,470×2,300mm로 변경)으로 나눈 안을 추가했다. 원본 `booth-2sheet.html`, PNG는 `booth-png-2sheet/`(뒷벽 장당 2940×4600px, 옆벽 장당 1576×2466px, `wall-*.png`는 벽 전체 보기). 뒷벽은 헤드라인 1줄·설명·학생·작품 요점을 왼쪽 장에, 2줄·작품 카드·교사·준비물 요점을 오른쪽 장에 둔다. 옆벽 이미지는 가운데 이음선에 다리 난간만 걸리도록 다시 만든 `assets/lounge-studio-wide-2.png`다. 3장 안(`booth-6panel.html`, `booth-png/`)은 보존한다. 실제 시트 크기는 출력업체와 확인한다.

같은 날 뒷벽 문구를 바꿨다. 헤드라인 「바이브코딩, / AI활용 수업」, 설명 「자신만의 이야기와, 공감능력을 발휘해 인문학과 기술이 만나는 공간」, 작품 카드 캡션은 제목 대신 「영어 학습게임」「그래프 탐구」만 크게(썸네일에 제목이 있음). `booth-2sheet.html`에만 적용했고 3장 안은 이전 문구 그대로다.

2026-11-17 B2의 헤드라인·작품 영역을 위로 올리고, 기존 두 작품 아래에 [태양계 탐구하기](https://lounge.letscoding.kr/works/leco/solor)와 [음주운전 시뮬레이션](https://lounge.letscoding.kr/works/seuolstationnewspaperthief/joowan-car)을 추가해 **2×2, 총 4개**로 배치했다. 두 공개 페이지의 썸네일은 `public/landing/works/solor.webp`, `joowan-car.webp`에 저장했다. 최종 설치 순서는 **왼쪽 B2(AI활용 수업·작품), 오른쪽 B1(바이브코딩·설명)**이다. 파일 번호는 유지하며 `booth-png-2sheet/back-B1.png`, `back-B2.png`, `wall-back.png`를 기존 해상도로 재출력했다. 작품 격자·글자 잘림·가림 구역·개별 패널 표시를 확인했다. 옆벽과 3장 안은 그대로다.

### 족자봉 인쇄용 PDF

147×230cm 시트 4장을 족자봉으로 출력한다. 파일은 `../pdf/expo-banner-147x230/`에 장마다 RGB(`*-rgb.pdf`)와 CMYK PDF/X-4(`*-cmyk.pdf`, Japan Color 2001 Coated) 두 종류이고, 이름 앞 번호가 설치 순서다(1 뒷벽 왼쪽 B2, 2 뒷벽 오른쪽 B1, 3 옆벽 왼쪽 S1, 4 옆벽 오른쪽 S2). 완성 크기 1,470×2,300mm 그대로이며 도련은 넣지 않았고, 위아래 봉 감김 부분은 230cm 안에 포함된다고 보고 위아래 50mm 안에 글자·카드가 없는지 출력 스크립트가 확인한다(B2 오른쪽 위 퍼즐 장식만 조금 걸린다). 뒷벽 글자는 벡터, 사진·작품 썸네일은 원본 해상도다. 작품 썸네일 원본이 560×315px라 560mm 폭 카드에서 약 25dpi, 옆벽 이미지는 약 27dpi로 가까이서 보면 거칠 수 있다.

```sh
EXPO_PLAYWRIGHT=/path/to/playwright EXPO_CHROME=/path/to/chrome node output/ai-edu-expo/export-banner.cjs
for f in output/pdf/expo-banner-147x230/*-rgb.pdf; do SRC="$f" OUT="${f%-rgb.pdf}-cmyk.pdf" TITLE="렛츠코딩 라운지 엑스포 족자봉 147x230" sh output/ai-edu-expo/export-cmyk.sh; done
```

### 인포데스크 정면 (2026-11-17)

`info-desk.html`은 950×660mm 비율의 데스크 정면 검토안이다. 사용자가 제안한 「단계별 AI활용과, 평가과정에 도입하여, 미래형 수업으로 발전」을 「단계별 AI 활용, / 평가 과정까지. / 미래형 수업으로.」로 정리했다. `booth-2sheet.html`의 남색·보라·코랄과 사선 구성을 이어가며, 마지막 줄을 가장 크게 강조한다. 평가 과정에 AI를 도입한다는 방향이며 자동 평가 기능을 뜻하지 않는다. 기존 부스 테마 안의 추가 시안으로, 이전 방향 선택 기록은 `../expo-booth/direction-approved.md`, 최신 벽면 방향은 위의 「벽당 2장 안」을 따른다.

벽면 시안 상단 링크로 이동할 수 있다. 저장소 루트에서 정적 서버를 실행해 확인하며, 미리보기는 `info-desk.png`다. 2026-11-17 인쇄용 PDF를 `../pdf/expo-info-desk-950x660/`에 만들었다. RGB(`info-desk-950x660-rgb.pdf`)와 CMYK PDF/X-4(`-cmyk.pdf`, Japan Color 2001 Coated) 두 종류이며 950×660mm 완성 크기, 도련 없음, 글자 벡터 유지다. `export-banner.cjs`가 족자봉과 함께 출력하고 가장자리 20mm 안에 글자가 없는지 확인한다.
