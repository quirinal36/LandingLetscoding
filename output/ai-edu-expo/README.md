# AI EDU Expo 공교육 브로셔

- 수정 기획: [공교육 브로셔 수정 제안](revision-proposal.md) — 8장별 구성, 문구 초안, 화면 재사용 및 추가 확보 계획.
- 편집 원본: `index.html` — PowerPoint 8장의 순서와 문구를 유지한 HTML.
- 확인 주소: `/ai-edu-expo` (`npm run dev` 실행 후 접속).
- 1·2·4·6쪽 제목과 본문은 HTML에서 수정한다. `source-text.json`은 PPTX에서 추출한 문구 대조용이다.
- `assets/image1.png`~`image7.png`는 PPTX 원본 이미지다. 3·5·7쪽 도식과 8쪽 요금표 내부 문자는 이미지에 포함되어 있으므로 수정하려면 이미지를 교체하거나 HTML로 별도 재구성한다.
- 화면 최대 폭은 1200px. 작은 화면에서는 본문을 재배치하며, 상세 도식과 요금표는 원본 비율을 유지한다. 인쇄는 원본과 같은 16:9 가로 8쪽이며 요금표를 한 쪽 안에 축소한다.
- 새 라우트는 기존 `/brochure`처럼 HTML 원본을 읽고 폰트와 이미지를 삽입한다. 배포 시 수정 내용을 반영하려면 다시 빌드한다.
- 검증: `node output/ai-edu-expo/check.mjs http://127.0.0.1:3100/ai-edu-expo` (서버 없이 원본만 검사하려면 URL 생략). 문구를 의도적으로 수정한 뒤에는 대조 기준인 `source-text.json`도 함께 갱신한다.

원본: OneDrive의 「AI EDU Expo 공교육 브로셔 제작」(8장), 2026-10-11 추출. 기존 10쪽 브로셔 및 긴 상세페이지와 별도 파일이다. 이 파일의 8쪽은 Lite/Plus/Pro 5x 요금표이며, 이전 브로셔의 폐기된 ‘4주 무료·29,000원’ 페이지와 다르다.
