# 해커톤을 위한 AI바이브코딩 플랫폼

홈페이지에 게시하는 해커톤 활용 소개 HTML 슬라이드 12장입니다. 2026-11-13에 특정 대회 제안서에서 일반 소개 페이지로 바꿨습니다. 참가 인원·대회 기간·운영사 제안 문구는 넣지 않으며 `check.mjs`가 이를 검사합니다.

- 제공 경로: `/hackathon` (배포 후 기존 사이트 도메인에서 공개 접근)
- HTML 원본: `index.html`
- 제공 코드: `src/app/hackathon/route.ts`
- 화면 에셋: `public/hackathon/`
- 발표: 이전·다음 버튼, 방향키, PageUp/PageDown, Home/End, 슬라이드 선택
- 열람: 전체 보기, 화면 이미지 확대, 전체화면, 인쇄/PDF
- 직접 연결: `/hackathon#slide-6`처럼 장별 링크 지원
- JavaScript가 없으면 모든 슬라이드를 순서대로 표시합니다.

## 내용

1. 해커톤을 위한 AI바이브코딩 플랫폼 (표지: 왼쪽 제목, 오른쪽 절반에 스튜디오·라운지 소개 일러스트)
2. 비개발자의 아이디어·바이브코딩·데이터베이스·배포
3. Studio와 AI 바이브코딩 도구
4. 데이터베이스와 미디어
5. 제작 환경에서 배포
6. 모든 팀의 작품 탐색과 상호 체험
7. 커뮤니티·가상 투자·브랜딩과 마케팅
8. 제품 완성도와 AI 활용 과정의 평가 예시
9. 3일 운영 예시
10. 기간과 금액에 맞춘 토큰 예산
11. 대회 종료 후 성과 활용
12. 도입 문의

## 500×500 정사각 표지

- 원본: `cover-square.html`. 1쪽 밝은 표지와 같은 색 규칙(남색 제목, 남보라 강조, 하늘색→라벤더 배경)을 쓴다.
- 이미지: 사용자가 만든 `output/lounge-studio-cross-tall.png`(941×1672, 9:16)를 `public/hackathon/lounge-studio-cross-tall.png`로 복사해 사용한다. 높이 500px에 맞춰 잘림 없이 오른쪽 약 281px에 넣고, 왼쪽 가장자리를 흐려 배경과 잇는다.
- 출력: `PW=… CHROME=… node output/hackathon-proposal/export-square.cjs` → `output/pdf/hackathon-cover-square-500.png`, `-1000.png`(2배).

## 출처와 표현 범위

- 플랫폼 활용·기능·기간별 AI 토큰 예산은 사용자가 제공한 제품 설명을 반영했습니다. 영상생성 및 기간별 예산 설정은 이번 화면 캡처에서 동작 검증하지 않았습니다.
- 운영 화면은 Aside로 2026-11-06 캡처했습니다. 원본과 관찰: `output/studio-proposal/capture-notes.md`, `hackathon-capture-notes.md`.
- 「하늘을 나는 자동차」는 강의 시연 작품입니다. 「반응속도 테스트」는 황도복숭아의 공개 작품이며 두 작품은 다릅니다.
- 표지 이미지는 사용자가 만든 `output/lounge-studio-cross.png`(1122×1402)를 `public/hackathon/lounge-studio-cross.png`로 복사해 사용합니다. 오른쪽 절반을 채우도록 위아래 일부가 잘리며, 모바일에서는 전체를 표시합니다.
- 표지만 밝은 테마입니다. 배경은 일러스트 왼쪽 가장자리 색에 맞춘 하늘색→라벤더 세로 그라데이션, 제목은 남색(#142047), 강조는 남보라(#4a3fce)입니다. 이미지 왼쪽 6%를 투명하게 흐려 배경과 잇습니다. 2~12쪽의 어두운 테마와 민트 강조는 그대로입니다.
- 일정·평가 기준·예산 배분은 운영 예시입니다. 자동 평가·자동 집계·비용 자동 차단·영구 보관을 약속하지 않습니다.
- 화면에는 기존 운영 계정과 공개 작품의 닉네임·지표가 표시되어 있습니다. 대회 전용 화면이나 대회에서 얻은 성과로 표현하지 않습니다.
- 이미지 내용은 변경하지 않았습니다. 4쪽의 도구 이미지는 CSS로 왼쪽 패널을 강조하며 클릭하면 원본 전체가 열립니다.

## 검증

```sh
node output/hackathon-proposal/check.mjs
node output/hackathon-proposal/check.mjs http://127.0.0.1:3000/hackathon
```

별도 서비스 등록이나 외부 라이브러리 없이 기존 Next.js 정적 Route Handler 패턴을 사용합니다. 메인 메뉴·사이트맵에는 추가하지 않았습니다.

검증 결과: 12장 및 에셋 검사, `/hackathon` 응답, ESLint, `npm run build -- --webpack` 통과. Aside로 데스크톱·모바일·태블릿 및 화면 확대·장별 링크·인쇄 미디어를 확인했습니다. 기본 Turbopack 빌드는 이 실행 환경의 포트 바인딩 제한으로 완료하지 못했습니다. 실제 운영 배포와 물리 프린터 출력은 수행하지 않았습니다.
