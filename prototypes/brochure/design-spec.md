# 렛츠코딩 라운지 가로 A4 소개서 · 최종 구성

상태: 사용자가 “B 선택할게”로 비즈니스 제안서형을 선택했다. 선택한 표지와 기능 소개 쪽(현재 7쪽)의 편집 체계를 유지하여 전체 8쪽을 제작한다. 선택 기록은 `direction-approved.md`, 전체 원본은 `brochure.html`, 인쇄 파일은 `../../output/pdf/letscoding-lounge-brochure.pdf`다.

## 목적과 독자

코딩학원 원장님이 비즈니스 미팅에서 받고, 미팅 후에도 다시 읽을 수 있는 소개서다. 우편 발송용 출력물과 이메일로 전달하는 PDF가 같은 내용을 담는다. 랜딩의 긴 스크롤 이야기를 종이의 읽기 순서로 재구성한다. 독자는 AI 시대에 무엇을 가르칠지 고민하고, 한 학생이 수업을 오래 이어갈 수 있는 교육 경험과 실제 운영 방식을 알고 싶어 한다. 학부모용 광고로 바꾸지 않는다. 한 쪽에는 하나의 질문과 답을 담고, 핵심 문장과 실제 작품을 먼저 보이게 한다.

## 확정한 8쪽 구성

| 쪽 | 역할 · 제목 | 담을 내용 | 현재 랜딩 섹션 |
|---|---|---|---|
| 1 | 표지 · 학생 한 명이, 스타트업이 됩니다. | 만들고, 알리고, 투자를 받습니다. 실제 작품 이미지, 렛츠코딩 라운지 이름과 회사 로고 | 1 |
| 2 | 교육 변화 · 무엇을 만들지 정하고, 끝까지 만드는 힘 | 무한한 지식에서 무한한 실행으로. 기획·문제 정의·AI 활용·생각 근육·공감 근육·회복탄력성 | 2 |
| 3 | 학생의 경험 · 만들고 공유하기, 성장하고 기록하기 | 고른다 → 만든다 → 올린다 → 설명한다. 4주 프로젝트와 개발일지·작품소개영상·포트폴리오 | 3, 7 |
| 4 | 실제 활동 · 아이디어가 작품과 기록으로 남습니다 | 허용된 작품 예시와 기준일이 있는 운영 실측 | 7, 8 |
| 5 | 라운지 소개 · 다음 달도, 그다음 달도. 이어지는 프로젝트 수업. | 기존 교육·교구에서 AI와 바이브코딩 프로젝트로 확장 | 솔루션 소개 C안 |
| 6 | 주제 공급 · 다음 프로젝트의 주제, 혼자 고민하지 마세요. | 학생 아이디어, 지역사회 문제, 매달 5개의 이달의 문제와 다음 달로 이어지는 경험 | 솔루션 소개 C안 |
| 7 | 라운지 기능 · 성장으로 이어지는 공간 | 작품공유·가상경제·과제관리와 실제 목록 화면 | 4, 5, 6 |
| 8 | 도입과 연락처 · 반 하나로 충분합니다. | 4주 무료, 월 11,000원, 첫 수업 코칭, 연락처와 QR | 9, 10 |

8쪽은 A4 4장 분량이다. 현재는 A4 한 쪽씩 전달하거나 양면 출력하는 용도를 기준으로 한다. 제본 방식과 인쇄소 납품 규격은 확정 후 맞춘다.

## 공통 디자인 조건

- 최종 종이 크기: 297 × 210mm, 가로 A4. 각 `.sheet`는 이 크기로 고정한다. 화면의 좌표 기준은 약 1122.52 × 793.70 CSS px이다.
- 중요한 글과 로고는 종이 끝에서 최소 12mm 안쪽에 배치한다. 기본은 흰 종이에 출력 가능한 구성이고, 큰 배경색이 있는 방향도 본문은 충분한 대비를 유지한다.
- 제목은 30–44pt, 본문은 최소 10.5pt(14px), 캡션은 최소 9pt(12px). 기존 Pretendard를 사용하며 작은 글씨로 정보를 억지로 넣지 않는다.
- 회사의 기존 로고와 공개 사용이 허용된 실제 작품 및 제품 화면을 사용한다. 새로운 그림이나 가상의 사용자 화면, 재원율·매출 개선 등의 효능 수치를 만들지 않는다.
- 세 방향은 동일한 문구와 이미지를 바탕으로, 배치와 읽는 순서를 다르게 한다. 색만 바꾸는 변형은 만들지 않는다.
- 미리보기 파일은 이 저장소의 자산을 상대 경로로 참조한다. `python3 -m http.server 4178 --bind 127.0.0.1`을 저장소 루트에서 실행한 뒤 `/prototypes/brochure/index.html`을 연다. 외부 CDN과 추가 패키지를 사용하지 않는다.
- 대표 시안은 방향별 독립 HTML 한 파일 안에 2개 `.sheet`를 두며 보존한다. 최종 `brochure.html`은 8개 `.sheet`를 둔다. 출력 시 여백을 제거하고 A4 한 쪽씩 나뉜다. `index.html`은 실제 PDF에서 렌더한 8쪽을 보여 준다.

## 세 방향이 함께 사용할 대표 페이지 문구

### 1쪽 · 표지

- 브랜드: 렛츠코딩 / LETSCODING LOUNGE
- 분류: 코딩학원을 위한 AI 시대 커리큘럼
- 제목: 학생 한 명이, / 스타트업이 됩니다.
- 핵심 문장: 만들고, 알리고, 투자를 받습니다.
- 설명: 7년차 코딩학원이 만들어 매일 쓰는 렛츠코딩 라운지
- 하단: www.letscoding.kr
- 이미지: `english.webp`, `absolute-pitch.webp`, `pixel-art-maker.webp`. 제목은 각각 삐약! 영어 탐험, 절대음감 테스트, 픽셀아트 변환기. 설명에 필요하면 "라운지에 공개된 작품 예시"로 표기한다.

### 4쪽 · 라운지 기능

- 분류: 렛츠코딩 라운지
- 제목: 작품이 수업을 넘어, / 성장으로 이어지는 공간.
- 도입: 작품공유 · 가상경제 · 과제관리, 세 축이 하나의 교육 사이클로 연결됩니다.
- 작품공유: 내가 만든 게임과 웹사이트를 올리고, 서로 플레이하며 반응을 주고받습니다.
- 가상경제: 작품 조회와 과제 완료로 루캣이 쌓이고, 친구의 작품에 투자하며 경제를 경험합니다.
- 과제관리: 매달 5개의 새 문제와 학습과제 193개. 제작부터 게시와 소개 영상까지 이어집니다.
- 하단 요약: 만들기 → 공유하기 → 반응과 투자 → 다음 작품
- 하단 안내: 4주 무료 파일럿 · 반 하나로 시작할 수 있습니다.
- 이미지: `works-grid.jpg`를 실제 목록 화면으로 사용한다. 다른 내용이 필요하면 `monthly.png`와 `learning.png`만 추가한다.
- 실제 화면의 표기: 라운지 실제 작품 목록 · 공개 사용이 허용된 나나쌤 작품
- 운영 수치는 4쪽에서 쓰므로 대표 본문에 억지로 추가하지 않는다.

## 최종 검증과 재출력

- 사용자 요청: “라운지 소개하는 내용이 브로셔의 뒷부분에 배치되어야 하겠어”. 앞 1~4쪽은 교육과 실제 활동, 뒤 5~8쪽은 솔루션의 확장·주제 공급·기능·도입 순서로 편집한다.
- `check.cjs`는 8쪽 수, 후반의 내용 순서, 가로 A4 크기, 12mm 안전 영역, 최소 글자 크기, 누락 자산, 가격·연락처·통계, QR 링크와 모바일 미리보기를 검사한 뒤 PDF를 출력한다.
- 재출력: `BROCHURE_PLAYWRIGHT=/path/to/playwright BROCHURE_CHROME=/path/to/chrome node prototypes/brochure/check.cjs`.
- 실제 PDF 미리보기: `pdftoppm -png -r 110 output/pdf/letscoding-lounge-brochure.pdf prototypes/brochure/previews/final/page`.
- 출력: A4 / 가로 / 실제 크기 100% / 페이지당 1쪽. 양면은 짧은 쪽 넘김. 8쪽은 4장이다.
- HTML 원본과 PDF는 저장하며 PNG는 기존 정책에 따라 로컬에 둔다.
