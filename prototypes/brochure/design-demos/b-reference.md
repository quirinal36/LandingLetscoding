# B안 · 실제 참조의 편집 원칙 이전

## 확인한 공식 참조

- [IBM Design Language · 2x Grid](https://www.ibm.com/design/language/2x-grid/) — 2026-09-30 확인. 종이에도 적용하는 그리드, 실제 콘텐츠 영역을 기준으로 하는 열 분할, 일관된 간격과 이미지 비율을 설명한다.
- [IBM Design Language · Type basics](https://www.ibm.com/design/language/typography/type-basics/) — 2026-09-30 확인. 왼쪽 정렬, 단순한 제목 위계, 짧은 읽기 폭, 적절한 행간, 여러 줄 제목의 원칙을 확인했다.

## 이번 소개서로 옮긴 원칙

흰 종이, 단정한 먹색과 기존 브랜드 파랑을 바탕으로 비즈니스 미팅에서 설명하고 다시 읽기 좋은 문서로 구성했다. 기본 콘텐츠 영역은 14mm 안전 여백 안의 8열이며, 주요 간격은 2mm의 배수를 사용한다. 큰 표지 제목과 짧은 소개를 5:3 영역에 나눠 놓고, 같은 크기의 실제 작품 세 개를 가로로 보여 준다. 4쪽은 실제 작품 목록과 기능 설명을 4:4 영역에 나란히 두었다. IBM의 화면이나 로고, 폰트, 문구는 옮기지 않았다.

형태는 이 콘텐츠의 ‘작품에서 다음 작품으로 이어지는 사이클’에서 나왔다. 표지는 결과물부터 보여 주고, 본문은 공개 목록의 실제 증거에서 공유·투자·과제의 읽기 순서로 이어진다. 별도의 모형 화면이나 장식 아이콘은 만들지 않았다.

## 구현과 한계

- `b.html` 안에 가로 A4 297 × 210mm인 `section.sheet` 두 개만 포함한다. ID는 `cover`, `page4`이며 인쇄 시 각 한 쪽으로 나뉜다.
- 공통 spec 문구, 기존 Pretendard, 원본 회사 로고, 허용된 작품 썸네일과 제품 화면만 사용했다. 본문 16px 이상, 캡션 13px 이상이다.
- 큰 목록 이미지는 상단 두 줄에 집중하도록 하단 일부를 잘랐다. 원본 픽셀을 수정하지 않았으며 실제 화면의 출처를 캡션에 적었다.
- 표지와 대표 4쪽을 비교하는 초안이다. 나머지 4쪽, 제본·재단·인쇄소 납품 규격은 포함하지 않는다. 최종 PDF와 브라우저 렌더링 검증은 부모 작업에서 수행한다.
