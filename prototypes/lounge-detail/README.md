# 렛츠코딩 라운지 학교용 상세페이지

`index.html`이 편집 원본이다. 최대 너비는 1200px이며 작은 화면에서는 단과 글자 크기를 조정한다. 상단은 랜딩의 히어로 → 무한대 마크 → 종이 팝업북 순서다. 나머지는 기존 브로셔의 B형 디자인으로 이어진다. 이전 버전은 `index-v1.html`에 보관한다.

## 완성 파일

- `../../output/lounge-detail/letscoding-lounge-detail.html`: 이미지·폰트를 내장한 단일 HTML. 파일을 다른 위치로 옮겨도 브라우저에서 열린다.
- `../../output/lounge-detail/letscoding-lounge-detail-1200.png`: 너비 1200px 전체 상세 이미지.
- `../../output/lounge-detail/sections/01.png`부터 `11.png`: 차례로 이어 붙이는 섹션별 이미지. 플랫폼의 이미지 높이 제한이 있을 때 사용한다.
- `../../output/lounge-detail/mobile-preview.png`: 390px 화면 검증용 미리보기. 재출력 스크립트로 생성하며 Git 관리에서는 제외한다.
- `../../output/lounge-detail/OFL.txt`: 내장 Pretendard 폰트 라이선스. HTML을 재배포할 때 함께 전달한다.

## 검증 및 다시 내보내기

기존 설치된 Playwright와 Chrome 경로를 사용하며 별도 의존성을 추가하지 않는다.

```sh
DETAIL_PLAYWRIGHT=/path/to/playwright DETAIL_CHROME=/path/to/chrome node prototypes/lounge-detail/export.cjs
```

폐기 문구, 필수 기능, 이미지·폰트 로딩, HTML 독립 실행, 320~1440px의 일곱 화면 크기와 가로 넘침을 검사한 뒤 이미지를 출력한다. 상단 세 구간의 순서, 종이 장면 네 개의 정지 출력, HTML의 스크롤 애니메이션도 검사한다. PNG는 정지 이미지이므로 종이 애니메이션의 네 장면을 모두 펼쳐 보여준다.

## 콘텐츠 범위

브로셔 1~9쪽과 랜딩 1~6번을 재구성했다. 브로셔 10쪽 및 랜딩 7~13번의 구성은 포함하지 않는다. 가격·4주 무료는 다른 쪽에 반복된 문구까지 모두 제외했다. 학교 대상으로 표현을 고쳤으며 기존 랜딩·브로셔 원본에는 영향을 주지 않는다.

1. 랜딩 히어로: 학생 한 명이 스타트업이 됩니다 + 세 줄 작품 배열
2. 무한대 마크 + 교육 방향과 여섯 가지 역량
3. 종이 팝업북 네 장면: 만들고 · 공유하기 · 성장하고 · 기록하기
4. 배운 코딩에서 실제 작품으로
5. 학생 아이디어·주변 문제·추천 과제
6. 공동체와 실제 라운지 화면
7. 작품공유·가상경제·과제관리의 연결
8. 랜딩의 기능소개 카드 세 개를 펼친 구성
9. 웹에디터 제작·미리보기·배포 (브로셔 8쪽)
10. 프로젝트 기록·AI 활용 관리 (브로셔 9쪽)
11. 서비스명과 실제 작품 링크
