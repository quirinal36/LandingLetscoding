# 레퍼런스 분석 — AI SYNC CLUB · REEL 2026

Threads에서 녹화한 18초짜리 영상(1016×572, 약 56fps, 무음)을 프레임 단위로 뜯어 본 기록이다.
이 폴더의 렛츠코딩 릴은 이 분석을 바탕으로 만들었다.

## 한 줄 요약

**15초 무한 루프, 128 BPM 박자 격자 위에 8개 씬이 한 마디(1.875초)씩 놓인 코드 기반 모션그래픽 릴.**
방송 모니터 같은 HUD가 모든 씬을 하나로 묶고, 씬마다 다른 기법을 하나씩 보여 준다.
HUD에 `60 FPS · 128 BPM`, 타임코드, 이징 함수 이름과 값이 그대로 찍혀 있는 것으로 보아
브라우저에서 코드(Canvas/JS)로 그린 화면을 녹화한 것이다.

## 뼈대

| 항목 | 값 |
|---|---|
| 길이 | 15.00초 루프. 녹화본 18초 = 루프 한 바퀴 + 앞뒤 일부 |
| 템포 | 128 BPM → 1박 0.469초, 1마디 1.875초 |
| 구성 | 8씬 × 1마디 = 32박 = 15초. 씬 3은 1박마다 화면이 바뀐다 |
| 화면 | 16:9, 60fps |
| 타임코드 | `TC 00:00:SS:FF` — FF는 60fps 기준 프레임 번호 |

**HUD (모든 씬 공통)**

- 왼쪽 위 `AI SYNC CLUB — REEL 2026`, 오른쪽 위 `2026 · 60 FPS · 128 BPM`
- 왼쪽 아래 타임코드, 가운데 아래 박자 표시 네 칸(지금 박자만 채워짐), 오른쪽 아래 씬 번호와 이름 `03/08 LEARN · APPLY · SHARE`
- 맨 아래 진행 막대
- 글자색은 배경 밝기에 따라 흰색/검정으로 바뀐다

## 좋아 보이는 이유 일곱 가지

1. **박자가 편집을 정한다.** 컷, 등장, 박자 표시가 모두 128 BPM 격자에 떨어진다. 소리를 꺼도 리듬이 보인다.
2. **씬 하나에 기법 하나.** 한 화면에 효과를 겹치지 않는다. 대신 여덟 씬이 모두 다른 기법을 쓴다.
3. **전환이 다음 씬의 첫 프레임이다.** 원이 커져 다음 바탕이 되고, 밑줄이 가로선이 되어 첫 씬을 연다. 컷이 보이지 않는다.
4. **색은 면으로 크게.** 네다섯 가지 색을 화면 전체 면으로 쓰고, 씬마다 바탕을 뒤집어 대비를 만든다.
5. **글꼴 대비.** 굵은 산세리프와 가는 세리프 이탤릭을 붙이고, 정보는 모노스페이스로 뺀다.
6. **만드는 과정을 숨기지 않는다.** 이징 그래프, 타임코드, FPS·BPM, 셀 좌표를 디자인 요소로 쓴다. "코드로 만든 것"이라는 사실 자체가 볼거리다.
7. **처음과 끝이 같은 프레임.** SNS에서 자동 반복 재생될 때 끊기지 않는다.

## 렛츠코딩 버전으로 옮기며 바꾼 것

기법과 순서는 그대로 두고, 씬이 말하는 내용과 색·글꼴을 렛츠코딩 것으로 바꿨다.

| # | 레퍼런스 | 렛츠코딩 | 문구 출처 (`src/app/page.tsx`) |
|---|---|---|---|
| 01 | AI SYNC / with AI | WHY CODE? / in the age of AI | 고민 1 “이제 AI가 코딩 다 해주는데, 코딩을 왜 배워요?” |
| 02 | CLUB (28,000+ crew) | IDEA | 답 “AI가 대신 못 하는 것을 시킵니다” |
| 03 | 배우고·써먹고·나누고·싱크 맞추고 | 정하고·만들고·내놓고·고치고 | 순환 CYCLE (다섯 단계 중 네 박자에 맞춰 네 개) |
| 04 | BUILD, A1–G12 좌표 | LOUNGE, `[행][열]` 배열 인덱스 + 작품 카드 | 라운지 “학생 작품이 사라지지 않는 학원” |
| 05 | sync. (people + AI) | grow. | 라운지 “진도표 대신 성장을 보여 줍니다” |
| 06 | 20 PROGRAMS | 196 STUDENT WORKS | PROOF 196건 · 44명 (2026.4.6–8.22 등록분) |
| 07 | SYNC 2026 | LET'S CODE 2026 | — |
| 08 | AI싱크클럽 + 노란 점 | 실행 화살표 마크 + 렛츠코딩 + 노란 커서 | 히어로 제목, 4주 무료 파일럿, 연락처 |

- **색**: 브랜드 토큰(`--color-accent` `#3b6fe0`, `--color-ink` `#1b2333`, `--color-bg` `#e9edf3`)에 파이썬 옐로 `#ffd43b` 하나를 더했다. 파랑+노랑은 파이썬 로고의 두 색이라 코딩 교육 브랜드에 이유가 선다. 메타볼은 레퍼런스의 오렌지 대신 브랜드 파랑으로, 글자는 방울 안에서만 노랑으로 바뀐다.
- **글꼴**: Pretendard(브랜드 서체)와 IBM Plex Mono(브랜드 모노)는 그대로, 세리프 이탤릭은 같은 Plex 가족의 IBM Plex Serif Italic으로.
- **렛츠코딩에만 있는 디테일**: 씬 6의 곡선은 9월 추천 과제 “내가 만든 수식이 시각적인 패턴이 되는 프로그램”처럼 수식(하이포트로코이드 R=5, r=3, d=5)을 그대로 보여 주고, 굴러가는 원과 팔을 옅게 드러낸다. 씬 4의 칸 번호는 좌표 대신 2차원 배열 인덱스 `[r][c]`, 씬 8의 마크는 사이트 로고와 같은 실행 화살표 path다.
- **수치 원칙**: 랜딩페이지 주석의 규칙(매출·상담·재등록 같은 효과 수치는 쓰지 않는다)을 따랐다. 쓰인 숫자는 196건·44명·4개월 반·4주뿐이다.
